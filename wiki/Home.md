# baram

Tauri 2.0 + Tiptap/ProseMirror + React 로 만든 경량 WYSIWYG 마크다운 에디터.

## 무엇이 어디 사는가

| 찾는 것                                 | 가는 곳                                         |
| --------------------------------------- | ----------------------------------------------- |
| 쓰는 법 (사용자 문서)                   | [baram.ing/ko/docs](https://baram.ing/ko/docs/) |
| 지금 무엇이 되고 무엇이 안 되나         | [이슈](https://github.com/sayinel/baram/issues) |
| 코드가 지켜야 하는 계약                 | 리포의 `CLAUDE.md` 와 각 모듈 헤더 주석         |
| **왜 이렇게 만들었나 (개발 내부 지식)** | **여기**                                        |

이 wiki 는 리포의 `wiki/` 에서 생성된다. 합성·색인 레이어이므로 **거의 변하지 않는 것**만
직접 싣고 — 아키텍처 불변식, 결정과 그 근거, 두 번 밟지 말아야 할 함정 — 자주 변하는 것은
위 표의 canonical 한 집을 가리킨다.
