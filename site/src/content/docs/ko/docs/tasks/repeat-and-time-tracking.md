## 슬래시 명령

커서가 태스크 줄에 있을 때:

| 명령           | 하는 일                                                    |
| -------------- | ---------------------------------------------------------- |
| `/due`         | 기한을 고릅니다(텍스트 칸 + 달력)                          |
| `/sched`       | 예정일을 고릅니다                                          |
| `/start`       | 시작일을 고릅니다                                          |
| `/priority`    | 목록에서 다섯 단계 중 하나를 고릅니다                      |
| `/repeat`      | 반복 규칙을 정합니다 — 값에 공백이 들어가므로 이것이 **유일한** 입력 경로입니다 |
| `/cancel-task` | 줄은 남기고 태스크를 취소 상태로 만듭니다                  |

`/extract-tasks`(**할 일 뽑아내기**)는 태스크 줄뿐 아니라 어디서든 동작합니다 — [AI 기능](/ko/docs/ai/templates-commands-and-skills/#할-일-뽑아내기) 참조.

날짜 대화상자에는 3단 달력이 있습니다. 가운데 라벨을 클릭하면 일 → 월 → 연으로 넓어지고, 칸을 고르면 다시 좁아집니다. 텍스트 칸에 입력하면 일 보기로 돌아옵니다. 월이나 연을 고르는 것은 보기만 옮기고, 값을 정하는 것은 일을 고르는 것뿐입니다.

## 기존 태스크 편집

모든 필드가 에디터에서 **칩**으로 렌더됩니다. 칩을 클릭하면 그 필드를 편집하고, 비우면 필드가 사라집니다. `Cmd+Alt+T`(**태스크 입력**, 재지정 가능)는 전체 대화상자를 엽니다 — 기존 태스크 줄에서는 **태스크 편집**, 그 밖에서는 **새 태스크**입니다. 모든 필드와 태그 칸, 그리고 만들어질 줄의 실시간 미리보기를 보여 줍니다. 태스크가 갈 수 없는 자리(제목, 표, 코드 블록)에서는 스스로 닫힙니다.

그 사이에 줄이 바뀌었으면 — 다른 창이나 외부 에디터에서 — 덮어쓰지 않고 쓰기를 거절하며, 대화상자가 그렇다고 알려 줍니다.

## 반복 규칙

`🔁` 규칙은 영어로 씁니다(다른 도구도 같게 읽도록) 그리고 이 모양을 지켜야 합니다.

```
every [N] day|days|week|weeks|weekday|month|months|year|years [on <기준>]
```

| 예                         | 뜻                             |
| -------------------------- | ------------------------------ |
| `every day`                | 매일                           |
| `every 2 weeks`            | 2주마다                        |
| `every weekday`            | 다음 영업일                    |
| `every week on Monday`     | 매주 월요일                    |
| `every month on the 15th`  | 매달 15일                      |
| `every year`               | 매년                           |

기준은 자기 단위에만 붙습니다 — `on Monday`에는 `week`가, `on the 15th`에는 `month`가 필요하고, `every weekday`는 간격도 기준도 받지 않습니다.

**반복 태스크를 완료하거나 취소하면 닫히지 않고 앞으로 굴러갑니다.** 시작일·예정일·기한이 모두 다음 차례로 옮겨지고, 상태가 `[ ]`로 돌아가며, 토스트가 새 날짜를 보여 줍니다. 줄은 여전히 한 줄입니다.

그렇게 할 수 없는 규칙은 칩에 그렇다고 적습니다.

- *repeats … (no date to move)* — `🔁`는 있는데 굴릴 날짜가 없습니다
- *repeats … (not understood)* — 규칙이 위 문법에 맞지 않습니다

## 시간 기록

기본은 꺼짐입니다. **설정 > 일반 > 태스크 > 진행 중인 태스크의 시간 기록**을 켜면, 태스크가 `[/]`에 있는 동안 `⏱` 필드를 적고 그 상태를 벗어날 때 지난 시간을 누적합니다.

```
⏱1h27m                      멈춤 — 지금까지 1시간 27분
⏱1h27m+2026-09-01T14:03     재는 중 — 그 시각부터 다시 세는 중
```

기본을 꺼 둔 것은 의도입니다. 그러지 않으면 태스크를 "진행 중"으로 바꾸는 것만으로 다른 앱도 읽는 파일에 필드가 하나 붙게 됩니다.
