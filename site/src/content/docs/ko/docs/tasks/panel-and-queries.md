## 태스크 패널

활동 표시줄에서 **태스크**(체크 원 아이콘)를 엽니다. 색인된 모든 태스크를 버킷으로 모으고, 순서는 이렇습니다.

| 버킷               | 담는 것                                                    |
| ------------------ | ---------------------------------------------------------- |
| **기한 초과**      | `📅` 기한이 지났다                                          |
| **예정 밀림**      | `⏳` 예정일이 지났으나 놓친 기한은 없다                     |
| **오늘**           | 오늘 기한                                                  |
| **이번 주**        | 이번 주가 끝나기 전 기한                                   |
| **나중**           | 그 뒤 기한                                                 |
| **예정 없음**      | 날짜가 아예 없다                                           |
| **이번 주 완료** / **완료** | 완료된 것                                         |
| **취소됨**         | `[-]`                                                      |

기한 초과와 예정 밀림을 나눈 것은 의도입니다 — 놓친 **기한**은 깨진 약속이고, 놓친 **예정일**은 밀린 계획일 뿐입니다. 주가 어느 요일에 시작하는지는 **설정 > 일반 > 태스크 > 주 시작 요일**입니다(기본 월요일). 버킷은 재시작 없이 자정에 넘어갑니다.

진행 중인 태스크는 자기 버킷을 따로 갖지 않고 날짜 버킷에 남습니다 — 붙들고 있다고 해서 마감이 바뀌지는 않으니까요 — 그리고 상태는 행에 표시됩니다.

위쪽의 **필터**: 자유 텍스트, 상태, 우선순위(`⏫ 높음+` / `보통` / `🔽 낮음−`), 태그, 링크된 노트, 그리고 **Someday** 토글. **아젠다 범위**가 어느 루트를 훑을지 정합니다 — 열려 있는 전체 볼트(기본), 현재 볼트, 태스크 홈.

**패널에서 일하기**

- 체크박스는 태스크를 그 자리에서 완료하고 파일에 기록합니다.
- 행을 클릭하면 그 태스크가 있는 노트의 그 줄로 이동합니다.
- 행 끝에 배지가 둘 있습니다. **`−Nd`**는 그 태스크를 그 버킷에 넣은 날짜에서 며칠 지났는지입니다(기한 초과에서는 기한, 예정 밀림에서는 예정일). **`Nd`**는 *묵힘* 툴팁과 함께, `➕` 등록일로부터 **30일**이 지나도록 끝나지 않았을 때 나타납니다.
- 행의 **분류 메뉴**에는 오늘 기한, 내일 기한, 날짜 고르기…, `#someday`로 미루기, 취소·재개, 줄 삭제가 있습니다.
- **기한 초과 태스크를 오늘로 다시 예약**은 확인 한 번으로 초과된 것 전부를 옮깁니다.
- **주간 리뷰**는 백로그를 한 번에 하나씩 훑습니다 — `j`/`k`로 이동, `x` 완료, `t` 오늘, `s` someday, `⌫` 삭제.
- **완료 항목 정리**는 *N*일(기본 30, 조정 가능) 이전에 끝난 것을 `tasks/archive/YYYY-MM.md`로 옮깁니다. 자동으로 정리되는 것은 없고, 정리된 태스크도 색인과 검색에 남습니다. 정리는 태스크 홈 범위에서만 제공되고 태스크 홈이 설정돼 있어야 합니다.

## 이 노트의 태스크

**백링크** 패널 아래에 **이 노트의 태스크** 구역이 있습니다. 볼트 어디에 있든 그 줄이 지금 열어 둔 노트로 링크하는 태스크를 모두 나열합니다(`Project Apollo`가 열려 있으면 `- [ ] Review the draft [[Project Apollo]]`가 나옵니다). 행은 아젠다와 똑같이 동작합니다 — 체크하고, 이동하고, 분류 키를 쓸 수 있습니다.

**Zettel 허브**에도 지금 손이 필요한 것만 보여 주는 간결한 태스크 구역이 있습니다 — 기한 초과와 오늘 기한, 최대 일곱 행, 그리고 **전체 보기**가 완전한 아젠다로 넘깁니다.

## 태스크 캡처하기

`Cmd+Shift+N`으로 **빠른 캡처**를 열고 `Cmd+Alt+T`를 눌러 태스크 모드로 바꿉니다. 쓴 것은 수집함 파일에 들어갑니다 — **태스크 홈**의 `tasks/` 하위 폴더 안 `inbox.md`이고, 태스크 홈의 기본값은 Zettel 디렉터리입니다.

Baram이 배경에 있어도 빠른 캡처를 태스크 모드로 여는 **전역 캡처 단축키**(**설정 > 일반 > 태스크**)도 지정할 수 있습니다. 기본값은 없습니다 — 전역 단축키는 시스템 전체에서 가로채므로 다른 앱이 이미 쓰는 조합을 빼앗을 수 있기 때문입니다.

## 쿼리 블록의 태스크

`source: tasks`를 쓴 ` ```query ` 블록은 태스크 목록의 어떤 조각이든 노트에 끼워 넣고, 그 결과는 체크할 수 있는 상태로 남습니다. 필드와 연산자 전체는 [쿼리 블록](/ko/docs/rich-content/query-blocks/#쿼리-블록)을 보십시오.

## 태스크 설정

전부 **설정 > 일반 > 태스크** 아래에 있습니다.

| 설정                             | 기본값             | 하는 일                                                              |
| -------------------------------- | ------------------ | -------------------------------------------------------------------- |
| 태스크 활성화                    | 켬                 | 볼트 전역 체크박스를 색인하고 태스크 패널을 보여 줍니다              |
| 제외할 폴더                      | 없음               | 색인에서 건너뛸 폴더를 쉼표로 구분해 적습니다                        |
| 주 시작 요일                     | 월요일             | 어떤 기한이 **이번 주** 버킷에 들어갈지 정합니다                     |
| 완료일 기록                      | 켬                 | 태스크를 체크하면 `✅`와 오늘 날짜를 덧붙입니다                       |
| 등록일 기록                      | 켬                 | 에디터에서 새로 쓴 태스크 줄에 `➕`를 붙입니다                        |
| 진행 중인 태스크의 시간 기록     | 끔                 | 태스크가 `[/]`인 동안 `⏱`을 적습니다                                 |
| 태스크 홈                        | Zettel 디렉터리    | 캡처한 태스크와 그 아카이브가 사는 폴더                              |
| 수집함 파일 이름                 | `inbox.md`         | `{태스크 홈}/tasks/` 안의 파일 이름                                  |
| 아젠다 범위                      | 열려 있는 전체 볼트 | 아젠다가 훑는 루트                                                  |
| 정리 기준 경과일                 | 30일               | **완료 항목 정리**가 대상으로 삼을 만큼 오래된 기준                  |
| 전역 캡처 단축키                 | 설정 안 됨         | 어디서든 빠른 캡처를 태스크 모드로 엽니다                            |
