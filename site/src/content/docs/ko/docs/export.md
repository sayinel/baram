**파일 > 내보내기** 메뉴나 내보내기 대화상자에서 문서를 내보냅니다.

## HTML

인라인 스타일이 들어간, 그 자체로 완결된 깔끔한 HTML을 만듭니다. 내보낸 파일에는 모든 서식과 수식 렌더, 코드 강조가 담깁니다.

## PDF

시스템 인쇄 대화상자를 거쳐 인쇄용 PDF를 만듭니다. 용지 크기(A4 / Letter)와 여백, 레이아웃을 조정할 수 있습니다.

## Notion

Notion과 호환되는 마크다운 파일로 내보냅니다. Notion이 이해하지 못하는 Baram 고유 문법은 자동으로 바꿉니다.

| Baram 문법                 | Notion 출력                        |
| -------------------------- | ---------------------------------- |
| `[[page]]` 위키링크        | `[page](page.md)` 표준 링크        |
| `> [!type]` 콜아웃         | 이모지를 앞에 붙인 인용문          |
| `$inline$` 수식            | `$$inline$$` 블록 수식             |
| `==text==` 강조            | `**text**` 굵게                    |
| `~text~` 아래 첨자         | 유니코드 아래 첨자 또는 `$_{text}$` |
| `^text^` 위 첨자           | 유니코드 위 첨자 또는 `$^{text}$`  |
| `[^id]` 각주               | 인라인 `(id)` + Notes 구역         |
| `((ref))` 블록 참조        | 제거됨                             |
| 정의 목록                  | `**용어**: 정의` 형태              |

## Pandoc 형식 (Word, LaTeX, EPUB, RST)

[Pandoc](https://pandoc.org/)이 설치돼 있으면 형식이 더 늘어납니다.

| 형식      | 확장자    | 설명                                                                 |
| --------- | --------- | -------------------------------------------------------------------- |
| **Word**  | `.docx`   | 편집 가능한 Word 문서. 서식용 참조 템플릿을 고를 수 있습니다         |
| **LaTeX** | `.tex`    | 학술·과학 문서용 조판 형식                                           |
| **EPUB**  | `.epub`   | Kindle·Apple Books 등에서 읽는 전자책 형식                           |
| **RST**   | `.rst`    | Sphinx 문서용 reStructuredText                                       |

**준비:**

1. 시스템에 [Pandoc](https://pandoc.org/installing.html)을 설치합니다
2. Baram이 PATH에서 Pandoc을 자동으로 찾습니다 — 쓸 수 있으면 내보내기 대화상자에 Pandoc 형식이 나타납니다
3. 내보내기 대화상자에서 Word 참조 템플릿을 고르고, 필요하면 Pandoc 실행 파일도 자동으로 찾아 줍니다

**Word 템플릿:**

Word(DOCX)로 내보낼 때 참조 템플릿(`.docx` 파일)을 고를 수 있습니다. Pandoc이 그 템플릿의 스타일 — 제목, 글꼴, 색, 머리글·바닥글 — 을 내보낸 문서에 적용합니다.

**마크다운 전처리:**

Baram은 내보내기 전에 확장 문법을 Pandoc이 이해하는 형태로 자동 변환합니다. 위키링크는 표준 링크로, 콜아웃은 굵은 글씨를 앞에 붙인 인용문으로, 강조는 굵게로 바뀌고, 아래·위 첨자는 HTML 태그를 씁니다.

**이미지:**

Word와 EPUB은 이미지를 문서 안에 내장하므로 Pandoc이 이미지 파일을 읽어야 합니다. Baram은 그 노트가 속한 vault 또는 폴더(열어 둔 것 중 그 노트를 담은 가장 좁은 것) 안에 있는 이미지만 읽게 합니다. 노트가 상대 경로(`![alt](img/diagram.png)`)로 가리키든 절대 경로로 가리키든 마찬가지이고, 그 파일을 Pandoc에 넘기는 문서 옆에 복사해 두어 Pandoc이 노트에 적힌 경로를 직접 열지 않게 합니다. 그 밖의 것 — 그 vault·폴더 밖으로 나가는 경로, `file:` URL, 웹 URL — 은 이미지의 alt 텍스트로 바뀌므로 마크다운 이미지는 내보내는 동안 네트워크 요청을 내지 않으며, 몇 개가 빠졌는지 알림으로 알려 줍니다. 에디터에서 크기를 조절한 이미지는 `<img>` 태그로 저장되는데, 같은 방식으로 그 크기 그대로 내장되고 표 셀 안의 줄바꿈도 유지됩니다. vault 안에 있는 것처럼 보이는 경로가 실제로는 밖을 가리키면(예: symbolic link) 내보내기는 그 이미지를 조용히 빼는 대신 멈추고 어떤 이미지인지 알려 줍니다. 찾을 수 없는 이미지 파일도 alt 텍스트로 바뀝니다. 저장한 적 없는 문서는 상대 경로의 기준 폴더가 없어 상대 경로 이미지도 alt 텍스트로 바뀝니다. vault나 폴더의 일부가 아니라 파일 하나만 단독으로 연 경우도 같습니다. 이미지를 내장하려면 그 폴더를 여세요. LaTeX와 RST는 이미지를 내장하지 않으므로 — Pandoc이 참조만 쓰고 파일을 열지 않음 — 그 형식에서는 이미지 destination을 이 규칙이 거르지 않습니다. 노트에 적은 raw 마크업 — `<video>`·`<details>` 같은 HTML, raw TeX, 그 밖의 writer 전용 블록 — 은 모든 형식에서 빠집니다. Word는 원래 raw HTML을 그리지 않았고, EPUB에서는 이미지와 같은 방식으로 파일을 가리킬 수 있으며, LaTeX 출력의 raw TeX는 컴파일할 때 같은 일을 할 수 있기 때문입니다. 예외는 Baram이 직접 쓰는 것뿐입니다. 표 셀 안의 `<br>`, 그리고 아래 첨자·위 첨자·밑줄의 `<sub>`·`<sup>`·`<u>` 태그입니다. `cover-image`·`css`처럼 Pandoc에 파일을 넘기는 frontmatter key도 같은 이유로 무시됩니다.
