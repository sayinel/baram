Baram은 자동 생성과 달력 이동이 되는 데일리 노트용 저널 시스템을 내장하고 있습니다.

## 설정

1. **설정**(`Cmd+,` / `Ctrl+,`)을 열고 **일반** 탭으로 갑니다
2. **저널** 토글을 켭니다
3. **찾아보기**를 눌러 저널 파일을 둘 폴더를 고릅니다(절대 경로여야 합니다)
4. (선택) 파일 이름 형식을 고릅니다: `YYYY-MM-DD.md`(기본) 또는 `YYYYMMDD.md`
5. (선택) 사용자 템플릿 파일(`.md`)을 고릅니다
6. 시작 동작을 고릅니다: **오늘의 저널 열기**(실행할 때 자동으로 열기) 또는 **아무것도 안 함**

## 데일리 노트 만들기

데일리 노트를 만들거나 여는 방법은 셋입니다.

**달력 사이드바:**

1. 저널 화면구성(`Cmd+Alt+3` / `Ctrl+Alt+3`)으로 바꾸거나 사이드바에서 달력 패널을 고릅니다
2. 미니 달력에서 날짜를 클릭합니다 — 그 저널 항목이 없으면 템플릿으로 만들어집니다
3. 항목이 있는 날짜에는 점이 붙습니다

**날짜 링크:**

1. `[[2026-02-27]]`을 씁니다 — 대상이 날짜인 위키링크입니다
2. 클릭하면 그날 항목이 열립니다. 아직 없으면 Baram이 만들지 물어봅니다
3. 저널 **안에서는** 맨 날짜 링크가 그 항목으로 바로 해석됩니다. 다른 볼트에서는 공간을 적습니다 — `[[Journal::2026-02-27]]`

항목으로 링크하지 **않고** 날짜만 쓰려면 `@`를 씁니다 — [@날짜](/ko/docs/linking/dates-references-and-navigation/#날짜) 참조. `@` 칩을 클릭하면 저널이 아니라 날짜를 바꾸는 달력이 열립니다.

**시작할 때 자동 생성:**
설정에서 "오늘의 저널 열기"를 켜 두면, 앱을 실행할 때마다 Baram이 오늘 항목을 자동으로 만들고 엽니다.

## 템플릿

사용자 템플릿은 다음 변수를 지원합니다.

| 변수            | 바뀌는 값           | 예           |
| --------------- | ------------------- | ------------ |
| `{{date}}`      | 전체 날짜           | `2026-02-27` |
| `{{year}}`      | 연                  | `2026`       |
| `{{month}}`     | 월(앞자리 0 채움)   | `02`         |
| `{{day}}`       | 일(앞자리 0 채움)   | `27`         |
| `{{dayName}}`   | 요일                | `Friday`     |
| `{{monthName}}` | 월 이름             | `February`   |

사용자 템플릿을 정하지 않으면 Baram이 YAML 전문과 날짜 제목이 있는 기본 템플릿을 씁니다.

## 주기 노트

데일리 항목 말고도 주간·월간·연간 노트를 지원합니다.

- **설정 > 일반 > 저널**에서 종류마다 켭니다
- 달력 사이드바에서 주 번호 열을 클릭하면 주간 노트, 월 헤더를 클릭하면 월간 노트, 연도를 클릭하면 연간 노트가 열립니다
- 주기 노트 종류마다 자기 템플릿을 둘 수 있습니다

## 사진 저널

- 끌어다 놓거나, 붙여넣거나, `/photo` 슬래시 명령으로 이미지를 넣습니다 — 저널 옆 `assets/` 폴더에 자동으로 저장됩니다
- **사진 갤러리**(`Cmd+Shift+I` / `Ctrl+Shift+I`)를 열면 저널 미디어를 **일**·**월**·**연** 단위로 묶어 훑을 수 있고, 키보드로 다니는 라이트박스가 있습니다(`←` / `→`로 이동, `Esc`로 닫기)
- 저널 항목에 놓은 동영상 클립도 사진과 나란히 갤러리에 나타나고 라이트박스에서 재생됩니다. **전체** / **사진** / **동영상**으로 걸러 봅니다
- 축소판과 라이트박스 이미지는 캐시된 미리보기라, 카메라 원본 크기 사진 1년치도 부드럽게 스크롤됩니다. 라이트박스에서 **원본 보기**를 누르면 원해상도 파일이 열리고, `Esc`는 그 보기를 먼저 닫아 라이트박스는 남깁니다

## 추억

- **추억** 보기(`Cmd+Shift+R` / `Ctrl+Shift+R`)를 열면 지난 항목을 연도별로 다시 봅니다
- 탭이 둘입니다: 저널(한 줄 또는 전체)과 사진
- 올해의 한 줄 요약은 그 자리에서 편집할 수 있습니다

## 연속 기록과 통계

- 며칠 연속으로 썼는지(**연속 기록**)를 추적하고, 월간·연간 통계와 기여 히트맵을 봅니다

## 저널 테마

**설정 > 일반 > 저널**에서 앱 테마와 별개인 저널·달력 전용 테마를 고를 수 있습니다.
