## 인라인 서식

Baram은 글을 쓰는 동안 마크다운 문법을 숨깁니다. 서식이 걸린 텍스트에 커서가 들어가면 구분자가 나타나고, 벗어나면 사라집니다.

| 서식              | 문법          | 단축키 (macOS)   | 단축키 (Win/Linux)   |
| ----------------- | ------------- | ---------------- | -------------------- |
| **굵게**          | `**text**`    | `Cmd+B`          | `Ctrl+B`             |
| *기울임*          | `*text*`      | `Cmd+I`          | `Ctrl+I`             |
| <u>밑줄</u>       | `<u>text</u>` | `Cmd+U`          | `Ctrl+U`             |
| ~~취소선~~        | `~~text~~`    | `Cmd+Shift+X`    | `Ctrl+Shift+X`       |
| ==강조==          | `==text==`    | `Cmd+Shift+H`    | `Ctrl+Shift+H`       |
| 위 첨자           | `^text^`      | —                | —                    |
| 아래 첨자         | `~text~`      | —                | —                    |
| `인라인 코드`     | `` `text` ``  | `Cmd+E`          | `Ctrl+E`             |
| [링크](#인라인-서식) | `[text](url)` | —              | —                    |
| 인라인 수식       | `$formula$`   | `$...$` 입력     | `$...$` 입력         |

텍스트를 선택하면 위쪽에 나타나는 **플로팅 툴바**로도 서식을 걸 수 있습니다. 툴바에는 굵게, 기울임, 취소선, 강조, 위 첨자, 아래 첨자, 코드 등의 버튼이 있습니다.

## 블록 서식

### 제목

`#`부터 `######`까지 입력하고 공백을 넣으면 H1–H6 제목이 됩니다. 단축키도 있습니다.

| 동작        | macOS             | Windows/Linux       |
| ----------- | ----------------- | ------------------- |
| 제목 1      | `Cmd+1`           | `Ctrl+1`            |
| 제목 2      | `Cmd+2`           | `Ctrl+2`            |
| 제목 3      | `Cmd+3`           | `Ctrl+3`            |
| 제목 4–6    | `Cmd+4` – `Cmd+6` | `Ctrl+4` – `Ctrl+6` |

### 목록

| 목록 종류           | 만드는 법                 | 단축키 (macOS)   | 단축키 (Win/Linux)   |
| ------------------- | ------------------------- | ---------------- | -------------------- |
| 글머리 기호 목록    | `- ` 또는 `* ` 입력       | `Cmd+Shift+8`    | `Ctrl+Shift+8`       |
| 번호 매기기 목록    | `1. ` 입력                | `Cmd+Shift+7`    | `Ctrl+Shift+7`       |
| 할 일 목록          | `- [ ] ` 또는 `- [x] ` 입력 | `Cmd+Shift+9`  | `Ctrl+Shift+9`       |

`Tab`으로 목록 항목을 들여쓰고 `Shift+Tab`으로 내어씁니다.

### 접기 (제목·목록)

Baram은 Obsidian 식으로 제목과 중첩 목록 항목을 접습니다.

**동작 방식:**

- **제목**: 제목(H1–H6)에 마우스를 올리면 여백에 접기 화살표가 나타납니다. 화살표를 클릭하거나 단축키를 쓰면 같은 수준 이상의 다음 제목이 나올 때까지 그 아래 내용이 접힙니다.
- **중첩 목록**: 하위 목록을 가진 항목에 접기 화살표가 나타납니다. 클릭하면 하위 항목이 접힙니다.
- **생략 표시**: 접힌 구간의 제목이나 목록 항목 뒤에 `...` 배지가 붙어 숨은 내용이 있음을 알립니다. `...`이나 화살표를 클릭하면 펼쳐집니다.

**단축키:**

| 동작        | macOS             | Windows/Linux      |
| ----------- | ----------------- | ------------------ |
| 접기/펼치기 | `Cmd+Shift+[`     | `Ctrl+Shift+[`     |
| 모두 접기   | `Cmd+Shift+Alt+[` | `Ctrl+Shift+Alt+[` |
| 모두 펼치기 | `Cmd+Shift+Alt+]` | `Ctrl+Shift+Alt+]` |

**중요한 성질:**

- 접기 상태는 **보기 전용**입니다 — 마크다운 문서를 바꾸지 않고, 실행 취소 기록에도 영향을 주지 않으며, 저장되는 파일도 그대로입니다
- 접기 상태는 **파일마다 유지**됩니다 — 탭을 옮겼다 돌아와도 접어 둔 그대로입니다
- **찾기 및 바꾸기**는 접힌 구간 안에서 검색어가 걸리면 그 구간을 자동으로 펼칩니다
- **목차 클릭**도 대상 제목 구간을 자동으로 펼칩니다
