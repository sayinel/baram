## 파일 만들기와 열기

| 동작           | macOS         | Windows/Linux  |
| -------------- | ------------- | -------------- |
| 새 파일        | `Cmd+N`       | `Ctrl+N`       |
| 파일 열기      | `Cmd+O`       | `Ctrl+O`       |
| 저장           | `Cmd+S`       | `Ctrl+S`       |
| 다른 이름으로 저장 | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| 탭 닫기        | `Cmd+W`       | `Ctrl+W`       |
| 빠른 전환      | `Cmd+K`       | `Ctrl+K`       |

왼쪽 사이드바의 파일 트리에서 파일을 열 수도 있고, **빠른 전환**(`Cmd+K`)으로 파일과 제목을 빠르게 오갈 수도 있습니다.

## 끌어다 놓아 파일 가져오기

Finder나 탐색기에서 파일이나 폴더를 파일 트리로 끌어다 놓으면 Baram이 그것을 놓은 자리의
볼트 안으로 복사합니다. 폴더는 하위까지 함께 복사됩니다.

- 같은 이름이 이미 있으면 덮어쓰지 않고 빈 이름을 골라 씁니다.
- 심볼릭 링크는 따라가지 않고 건너뛰며, 몇 개를 건너뛰었는지 알려 줍니다 — 복사한 파일 수만
  말하면 불완전한 복사에 대해 참인 문장이 되어 버립니다.
- 트리 아래 빈 공간이나 최상위 행에 놓으면 볼트 루트에 들어갑니다.

## 탭

Baram은 에디터 위쪽의 탭으로 여러 파일을 동시에 엽니다.

- **탭 전환** — 탭을 클릭하거나, `Ctrl+Tab` / `Ctrl+Shift+Tab`으로 최근 사용 순서(MRU)로 전환합니다
- **탭 닫기** — 탭의 `×`를 클릭하거나 `Cmd+W`를 누릅니다
- **탭 고정** — 탭을 우클릭해 **탭 고정**을 선택합니다. 고정한 탭은 좁은 아이콘으로 표시되고 실수로 닫히지 않습니다
- **실행 취소 기록 유지** — 탭마다 자기 실행 취소·실행 복귀 기록을 갖고 있어, 탭을 옮겨 다녀도 남아 있습니다

## 빠른 전환

`Cmd+K`(macOS) 또는 `Ctrl+K`(Windows/Linux)를 눌러 빠른 전환을 엽니다. 입력해서 찾을 수 있는 것:

- **파일** — 워크스페이스의 어떤 파일이든 빠르게 엽니다
- **제목** — `#`을 입력하면 제목으로 걸러지고, 어떤 파일의 제목으로든 바로 이동합니다

## 자동 저장

문서는 입력하는 동안 자동으로 저장됩니다. 저장되지 않은 변경은 탭의 점 표시로 알려 주며, 입력을 멈춘 뒤 곧 저장됩니다.

## 실행 취소와 실행 복귀

| 동작      | macOS         | Windows/Linux  |
| --------- | ------------- | -------------- |
| 실행 취소 | `Cmd+Z`       | `Ctrl+Z`       |
| 실행 복귀 | `Cmd+Shift+Z` | `Ctrl+Shift+Z` |
