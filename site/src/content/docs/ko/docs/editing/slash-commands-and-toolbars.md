## 슬래시 명령

빈 줄 맨 앞에서 `/`를 입력하면 슬래시 명령 메뉴가 열립니다. 어떤 블록 요소든 빠르게 넣을 수 있습니다.

**기본:**

- `/heading1` – `/heading3` — 제목 넣기
- `/bullet` — 글머리 기호 목록 넣기
- `/ordered` — 번호 매기기 목록 넣기
- `/task` — 할 일 목록 넣기
- `/quote` — 인용문 넣기
- `/hr` — 가로줄 넣기
- `/callout` — 콜아웃 블록 넣기
- `/toggle` — 토글(접히는) 블록 넣기
- `/toggle heading 1` – `/toggle heading 3` — 제목을 요약으로 쓰는 토글 넣기
- `/toc` — 목차 넣기

**리치 콘텐츠:**

- `/code` — 코드 블록 넣기
- `/math` — 수식 블록 넣기
- `/mermaid` — Mermaid 다이어그램 넣기
- `/table` — 표 넣기
- `/image` — 이미지 넣기
- `/link` — 링크 넣기

입력하면 메뉴 항목이 걸러집니다. AI 명령도 슬래시 메뉴에서 쓸 수 있습니다([AI 기능](/ko/docs/ai/setup-inline-and-ghost-text/) 참조).

## 플로팅 툴바

텍스트를 선택하면 위쪽에 서식 버튼이 있는 플로팅 툴바가 나타납니다. **굵게**, **기울임**, **취소선**, **강조**, **위 첨자**, **아래 첨자**, **인라인 코드** 등이 있습니다.

## 블록 핸들

블록(문단·제목 등)에 마우스를 올리면 왼쪽에 드래그 핸들이 나타납니다. 이것으로 할 수 있는 일:

- **끌기** — 블록의 순서를 바꿉니다
- **클릭** — 블록 종류 변환, 복제, 삭제 같은 항목이 있는 메뉴를 엽니다

## 컨텍스트 메뉴

에디터 안에서 우클릭하면 상황에 맞는 항목이 나옵니다.

- 텍스트 조작(오려두기, 복사하기, 붙여넣기)
- 블록 종류 변환
- 탭 관리(탭 고정, 탭 닫기, 다른 탭 닫기)
