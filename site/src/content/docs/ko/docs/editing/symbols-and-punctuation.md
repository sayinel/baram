키보드에 없는 문자를 넣는 방법이 세 가지 있습니다. 입력하면서 `:`로 고르는 제안, 둘러보며 고르는 선택기, 그리고 `->`를 `→`로 바꿔 주는 스마트 구두점입니다.

세 가지 모두 파일에 **문자 자체**를 씁니다. `:smile`로 고른 이모지는 마크다운에 `:smile:` 같은 shortcode가 아니라 `😄`로 들어가므로, 파일은 어느 편집기에서 열어도 똑같이 읽히는 표준 마크다운으로 남습니다.

## `:`로 기호·이모지 넣기

`:` 뒤에 이름을 두 글자 이상 입력하면, 일치하는 기호와 이모지 메뉴가 커서 옆에 열립니다.

| 입력      | 결과               |
| --------- | ------------------ |
| `:arrow`  | `→`와 다른 화살표 |
| `:smile`  | `😄`와 다른 웃는 얼굴 |
| `:heart`  | `❤️`                |
| `:+1`     | `👍️`                |
| `:화살표` | `→` — 한국어 키워드로도 찾습니다 |
| `:웃음`   | `😀`와 다른 웃는 얼굴 |

표의 문자는 첫 번째 결과, 즉 **Enter**가 넣는 문자입니다. 메뉴에는 가장 잘 맞는 여덟 개가 나옵니다.

- **↑ / ↓**로 메뉴를 움직이고, **Enter**나 **Tab**으로 선택된 항목을 넣습니다. 항목을 클릭해도 들어갑니다
- **Esc**는 메뉴만 닫고 입력한 글자는 그대로 둡니다. Vim 인서트 모드에서는 첫 **Esc**가 메뉴를 닫고, 두 번째 **Esc**가 노멀 모드로 돌아갑니다
- 계속 입력하면 목록이 좁혀집니다. 공백을 입력하면 검색이 끝납니다

`:`는 단어의 시작이어야 합니다 — 줄 맨 앞이나 공백 뒤입니다. 단어나 숫자 안의 콜론은 건드리지 않으므로 `10:30`, `https://`, `key: value`에서는 메뉴가 열리지 않습니다. 코드 블록, 인라인 코드(아직 닫지 않은 백틱 뒤 포함), 인라인 수식을 편집하는 동안에도 열리지 않습니다.

이모지는 한 가지 모습으로만 제공되며, 피부색 변형은 없습니다.

제안을 끄려면 **설정 > 마크다운**의 **타이포그래피** 제목 아래에서 **기호·이모지 제안**을 끕니다. 기본값은 켜짐입니다.

## 기호·이모지 선택기로 둘러보기

기호의 이름을 모를 때는 슬래시 메뉴에서 선택기를 엽니다. `/`를 입력하고 **Symbols & Emoji**를 고릅니다(`/sym`이나 `/emoji`로 찾을 수 있습니다). 선택기는 커서 자리에 열리고, 검색창에 바로 입력할 수 있습니다.

- **검색** — 영어나 한국어 키워드를 입력하면 모든 기호와 이모지에서 한꺼번에 찾습니다. 검색창을 비울 때까지 결과가 절 목록을 대신합니다
- **탭** — 해당 절로 건너뜁니다: 최근 사용, 기호(화살표·수학·통화·구두점·표시와 도형·기타 기호), 그리고 표정과 감정부터 깃발까지의 이모지 묶음
- **방향키**로 격자를 움직이고 **Enter**로 선택된 문자를 넣습니다. 문자를 클릭해도 들어갑니다. 선택된 문자의 이름은 아래쪽에 표시됩니다
- **Esc**를 누르거나 선택기 바깥을 클릭하면 아무것도 넣지 않고 닫힙니다. 커서는 원래 자리로 돌아갑니다

### 최근 사용

**최근 사용** 탭에는 가장 최근에 넣은 문자가 최대 24개까지, 최근 것부터 쌓입니다. 선택기와 `:` 메뉴 모두 기록되므로 `:` 메뉴에서 고른 문자도 여기에 나타납니다. 스마트 구두점이 바꾼 기호는 기록되지 않습니다. 이 목록은 Baram을 다시 시작해도 유지됩니다.

## 스마트 구두점

스마트 구두점은 입력한 문자열을 그것이 뜻하는 기호로 바꿉니다. **기본값은 꺼짐**입니다 — **설정 > 마크다운**의 **타이포그래피** 아래 **스마트 구두점**으로 켭니다.

| 입력  | 결과 | 참고 |
| ----- | ---- | ---- |
| `->`  | `→`  | |
| `<-`  | `←`  | |
| `<->` | `↔`  | |
| `=>`  | `⇒`  | |
| `<=`  | `≤`  | |
| `<=>` | `⇔`  | |
| `>=`  | `≥`  | |
| `!=`  | `≠`  | |
| `...` | `…`  | |
| `--`  | `—`  | 다음 글자를 입력할 때 바뀝니다. `a -- b`는 `a — b`가 됩니다 |

**치환 되돌리기** — 바뀐 직후에 **Backspace**를 누르면 입력한 대로 돌아갑니다. 다른 치환 위에 만들어진 기호는 한 단계씩 돌아갑니다: `<->`가 `↔`가 된 뒤 **Backspace**를 한 번 누르면 `←>`가 됩니다.

**바뀌지 않고 입력한 그대로 남는 곳:**

- 코드 블록, 인라인 코드, 그리고 같은 문단에서 아직 닫지 않은 백틱 뒤의 텍스트
- 편집 중인 인라인 수식
- 같은 문단 앞쪽에서 아직 닫지 않은 여는 기호 뒤의 모든 텍스트 — 위키링크(`[[…`), 링크 주소(`](…`), 각주(`[^…`), 블록 참조(`((…`), 스킬 변수(`{{…`) — 가 닫는 기호(`]]`, `)`, `]`, `))`, `}}`)를 만날 때까지. `[[a->b`는 닫을 때까지 `[[a->b`로 남으므로 링크가 원래 대상을 가리킵니다
- 입력 중인 HTML 주석(`<!-- …`), `://`가 든 단어(URL), 입력 중인 `#태그`
- 대시 세 개(`---`, 가로줄), 공백 없이 쓴 표의 구분 행(`|--|`), `-->`, 그리고 문단 맨 앞의 `--`
- 붙여넣은 글 — 입력한 글만 바뀝니다
- 스킬 파일 — frontmatter에 `name:`과 `description:`이 모두 있는 파일([Skills](/ko/docs/ai/templates-commands-and-skills/#skills) 참조)입니다. 여기서는 `->`가 화살표가 아니라 단계를 나타내는 경우가 많습니다

**주의할 점:** 산문에 쓴 명령줄 옵션 `--flag`는 `—flag`가 됩니다. 백틱 안에서 입력하면(`` `--flag` ``) 쓴 그대로 남습니다.
