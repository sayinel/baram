## 볼트 간 위키링크

다른 볼트의 파일로 링크하려면 볼트 별칭 접두어를 씁니다.

```
[[alias::filename]]
```

- `alias`는 **설정 > 볼트 > 별칭**에서 정한 그 볼트의 짧은 이름입니다
- `filename`은 대상 파일 이름입니다(`.md` 없이)

예: `[[work::meeting-notes]]`는 별칭이 `work`인 볼트의 `meeting-notes.md`로 링크합니다.

볼트 간 링크는 다른 스타일로 나타나고, 대상을 그 볼트의 컨텍스트에서 엽니다. 대상 볼트가 열려 있지 않으면 Baram이 열겠느냐고 묻습니다.

## 외부 파일 열기

현재 볼트 밖의 `.md` 파일도 **파일 > 파일 열기**(`Cmd+O` / `Ctrl+O`)로 열 수 있습니다. 그 파일은 📎 아이콘이 붙은 **파일 컨텍스트** 탭으로, 사이드바 없이 에디터만 열립니다. 워크스페이스 밖 파일을 잠깐 고칠 때 좋습니다.

## 다른 종류의 파일 보기

Baram은 마크다운 에디터지만, 몇 가지 다른 파일 종류는 다른 앱에 넘기지 않고 앱 안에서 엽니다.
파일 트리에서 클릭하거나 **파일 > 파일 열기**를 쓰십시오.

| 종류 | 확장자 | 볼 수 있는 것 |
| ---- | ------ | ------------- |
| **PDF** | `.pdf` | 페이지 이동, 찾기, 확대·축소, 페이지·하이라이트 사이드 패널, 그리고 노트에서 참조할 수 있는 텍스트·영역 하이라이트가 있는 리더. PDF 파일 자체는 절대 수정하지 않습니다. [PDF 읽기와 하이라이트](/ko/docs/pdf/toolbar-zoom-and-find/) 참조. |
| **HTML** | `.html`, `.htm` | 기본은 렌더된 실시간 미리보기이고, 구석에 **미리보기 / 소스** 전환이 있습니다. 소스로 바꾸면 구문 강조와 함께 마크업을 편집하고, 저장은 다른 파일과 같습니다. 미리보기는 샌드박스에서 돌아가므로 파일 안의 스크립트가 볼트나 앱에 닿을 수 없습니다. |
| **이미지** | `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.ico`, `.webp`, `.avif` | 창에 맞춰 보여 주는 뷰어. 작은 이미지를 억지로 늘리지는 않습니다. |
| **SVG** | `.svg` | 같은 뷰어가 벡터로 렌더합니다 — 어느 배율에서도 선명합니다. SVG 안의 스크립트는 실행되지 않습니다. |

이미지와 SVG는 Baram과 함께 오는 플러그인 **미디어 뷰어**가 담당합니다. 서드파티 플러그인이 쓰는
것과 같은 공개 `viewer` 확장점 위에 있으므로, Baram이 스스로 다루지 않는 파일 종류를 위한 뷰어를
플러그인이 더할 수 있습니다 —
[플러그인 개발 가이드](/ko/docs/plugin-dev/overview-and-capabilities/) 참조.

## 탭 떼어내기 (별도 창)

에디터 탭을 탭 바 밖으로 끌면 별도 창으로 떼어집니다. 그 창은 자기 에디터 상태를 갖고 독립적으로 동작합니다. 탭을 다시 탭 바로 끌면 원래대로 붙습니다.

## 화면구성

**화면구성**은 저장된 배치입니다 — 사이드바 패널, 오른쪽 패널, 테마 — 그리고 키 한 번으로 되살립니다. Baram은 넷을 함께 내놓고, 직접 더할 수도 있습니다.

### 내장 화면구성

| 화면구성 | 단축키 (macOS)   | 단축키 (Win/Linux)   | 배치                                                        |
| -------- | ---------------- | -------------------- | ----------------------------------------------------------- |
| 글쓰기   | `Cmd+Alt+1`      | `Ctrl+Alt+1`         | 에디터에 집중 — 오른쪽 패널 닫힘                            |
| Zettel   | `Cmd+Alt+2`      | `Ctrl+Alt+2`         | Zettel 허브(동작 + inbox + MOC + 최근) — 원자적인 제텔카스텐 노트 |
| 저널     | `Cmd+Alt+3`      | `Ctrl+Alt+3`         | 달력 사이드바 + 오늘의 저널 + 추억 보기                     |
| Skills   | `Cmd+Alt+4`      | `Ctrl+Alt+4`         | 파일 트리 + 속성 패널 — LLM Skills 편집                     |

> 넷 다 **설정 > 키 바인딩**(**화면구성** 분류)에서 조정할 수 있고 **화면구성** 메뉴에서도 쓸 수 있습니다. 공간을 바꿔도 열려 있는 폴더 트리를 강제로 닫지는 않습니다.

### 사용자 화면구성

**설정 > 모양**에서 직접 만듭니다.

1. 원하는 배치를 만듭니다(사이드바 패널, 오른쪽 패널, 테마)
2. **설정 > 모양**으로 가서 **현재 레이아웃 저장**을 누릅니다
3. 이름을 붙입니다

사용자 화면구성은 같은 설정 탭에서 이름을 바꾸고, 지우고, 적용할 수 있습니다.

### 화면구성 적용

- **키보드 단축키** — `Cmd+Alt+1`(글쓰기), `Cmd+Alt+2`(Zettel), `Cmd+Alt+3`(저널), `Cmd+Alt+4`(Skills)
- **화면구성 메뉴** — 메뉴 바에
- **설정 > 모양** — 사용자 화면구성용
