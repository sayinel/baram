볼트에는 노트 말고 다른 것도 들어 있을 수 있습니다. 코드 저장소를 볼트로 열면 `target`, `build`, `dist` 같은 빌드 산출물이 함께 들어오고, 그 파일은 수십만 개에 이르기도 합니다. Baram은 노트를 찾을 때 그런 폴더에 들어가지 않습니다. 그래서 그 폴더들은 링크 인덱스의 메모리도, 검색 시간도 쓰지 않습니다.

## 기본 목록

볼트 루트 아래라면 깊이와 상관없이 다음 이름의 폴더를 건너뜁니다.

| 폴더 | 보통 담고 있는 것 |
| -- | -- |
| `node_modules` | JavaScript 패키지 |
| `target` | Rust 빌드 산출물 |
| `build` | 여러 도구의 빌드 산출물 |
| `dist` | 패키징한 빌드 산출물 |
| `__pycache__` | Python 바이트코드 |
| `.next` | Next.js 빌드 산출물 |
| `.git` | Git 자체 데이터 |

이름이 `.`으로 시작하는 폴더도 건너뜁니다. 그런 파일도 모든 파일 검색을 뺀 모든 곳에서 건너뜁니다. 이 규칙은 목록과 별개이고 끌 수 없습니다.

판정 대상은 볼트 루트 **아래의** 폴더뿐입니다. 볼트 폴더 자체의 이름이 `build`여도 다른 볼트처럼 열리고 인덱스됩니다. 그 안에 있는 `build` 폴더만 건너뜁니다.

## 건너뛴 폴더가 빠지는 곳

건너뛴 폴더 안의 노트도 **파일 > 파일 열기**(`Cmd+O` / `Ctrl+O`)로 열어 고치고 저장할 수 있습니다. 다만 다음 기능에서는 빠집니다.

- [모든 파일 검색](/ko/docs/faq/editing/#모든-파일을-검색하려면)
- 링크, [백링크](/ko/docs/linking/dates-references-and-navigation/#백링크), [그래프](/ko/docs/linking/dates-references-and-navigation/#그래프-뷰). 건너뛴 폴더의 노트를 가리키는 링크는 대상을 찾지 못합니다
- [이름 변경](/ko/docs/linking/wikilinks-and-tags/#자동-이름-변경): 건너뛴 노트 안에 적힌 링크는 대상의 이름이 바뀌어도 고쳐 쓰이지 않습니다
- [태그](/ko/docs/linking/wikilinks-and-tags/#태그), 태그 이름 변경 포함
- [태스크 패널](/ko/docs/tasks/panel-and-queries/#태스크-패널)
- [명령줄](/ko/docs/command-line/)의 `files`, `search`, `tags`, `tasks`, `backlinks`, `links`

건너뛴 폴더의 노트를 저장해도 이 기능들에 다시 들어오지 않습니다.

## 볼트마다 목록 바꾸기: `.baramignore`

볼트 루트에 `.baramignore`라는 파일을 두면 그 볼트에서 건너뛸 것을 바꿀 수 있습니다. 문법은 `.gitignore`와 같습니다.

```text
# build 폴더의 노트는 내 것이니 다시 넣는다
!build/

# 초안과 내보낸 로그는 뺀다
drafts/
*.log
```

- 한 줄은 폴더(끝에 `/`)나 파일 패턴 하나입니다. 가운데에 `/`가 없는 패턴은 어느 깊이에서든 맞고, `/`로 시작하는 패턴은 볼트 루트 바로 아래에서만 맞습니다.
- `!`로 시작하는 줄은 앞의 줄이 뺀 것을 도로 넣습니다. 기본 목록의 폴더도 넣을 수 있습니다. 기본 목록이 앞의 줄로 치기 때문에 `!build/`가 통합니다.
- 건너뛴 폴더 안의 파일만 따로 도로 넣을 수는 없습니다. Baram이 그 폴더 안을 아예 보지 않기 때문에, `drafts/` 아래의 `!drafts/keep.md`는 아무 효과가 없습니다. 폴더를 도로 넣으십시오.
- `#`으로 시작하는 줄은 주석입니다.

Baram은 볼트 루트의 `.baramignore`만 읽습니다. 하위 폴더나 볼트 위쪽 폴더에 있는 것은 읽지 않습니다.

### `.gitignore`는 쓰지 않습니다

Baram은 `.gitignore`, `.ignore`, Git의 전역 제외 설정을 읽지 않습니다. 개인 일기처럼 Git에서 뺀 노트도 검색과 링크에 그대로 나옵니다.

### 바꾼 내용이 반영되는 때

검색, 태그, 명령줄은 실행할 때마다 파일을 다시 읽습니다. 링크 인덱스(링크, 백링크, 그래프, 이름 변경)는 인덱스를 만들 때, 곧 볼트를 열 때 읽습니다. `.baramignore`를 고친 뒤에는 볼트를 닫았다가 다시 열어야 모든 곳에 반영됩니다.

## `.baramignore`가 닿지 않는 곳

- 사이드바의 **파일 트리**는 기본 목록의 폴더만 숨깁니다. `!build/`로 도로 넣은 폴더도 트리에는 나오지 않고, `.baramignore`로 뺀 폴더는 트리에 그대로 나옵니다.
- **버전 히스토리**의 스냅샷도 기본 목록만 건너뜁니다. 검색에서 뺀 폴더라도 히스토리에서는 빠지지 않습니다.
