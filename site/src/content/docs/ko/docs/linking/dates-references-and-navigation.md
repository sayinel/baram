## @날짜

`@`는 **날짜**를 씁니다 — 글 속에서 어떤 날을 가리키는, 서식이 붙은 인라인 칩입니다.

1. **`@` 입력** — 빠른 날짜가 담긴 제안 팝업이 나타납니다
2. **빠른 날짜** — 오늘, 어제, 내일 (해석된 날짜가 함께 보입니다)
3. **날짜 고르기…** — 다른 날을 고를 달력을 엽니다
4. **직접 입력** — `YYYY-MM-DD` 전체를 그대로 넣어도 됩니다

**마크다운 문법:**

| 문법              | 설명                |
| ----------------- | ------------------- |
| `@[[2026-02-27]]` | 특정 날짜           |

**날짜 칩을 클릭하면 달력이 열리고 그 자리에서 날짜가 바뀝니다.** 이동하지 않습니다 — 날짜 언급은 어떤 날을 가리키는 값이고, 문서를 가리키는 것이 아닙니다.

**그날의 저널 항목을 열려면 링크로 쓰십시오** — `[[2026-02-27]]`. 날짜 링크가 어떻게 해석되는지는 [저널 / 데일리 노트](/ko/docs/journal/daily-notes/)를 보십시오.

**날짜와 위키링크의 차이:**

| | 뜻 | 클릭하면 |
| --- | --- | --- |
| `@[[2026-02-27]]` | 날짜 **값** | 달력이 열려 값을 바꾼다 |
| `[[2026-02-27]]` | 그날 항목에 대한 **참조** | 그 항목을 연다 |
| `[[내 노트]]` | 페이지에 대한 **참조** | 그 페이지를 연다 |

링크 색인에 모이는 것은 `[[…]]` 링크뿐이므로, 백링크와 그래프 뷰에 나타나는 것도 그것뿐입니다.

> **페이지 언급.** 이전 버전에는 페이지용 `@[[내 노트]]`도 있었습니다. `[[내 노트]]`와 같은 파일을 가리키면서 백링크에는 전혀 나타나지 않았기 때문에, 이제 `@`는 날짜 전용입니다. 이미 써 둔 페이지 언급은 그대로 렌더되고 Cmd+클릭(Windows·Linux는 Ctrl+클릭)으로 여전히 이동합니다. 새로 쓸 때는 `[[…]]`를 쓰십시오.

## 블록 참조

다른 문서의 특정 블록을 참조합니다.

1. **블록 ID 만들기** — 문단이나 제목 끝에 `^my-id`를 붙입니다
2. **블록 참조 넣기** — `((file#^my-id))`를 입력해 인라인 참조를 만듭니다
3. **블록 임베드 넣기** — `{{embed ((file#^my-id))}}`로 그 블록의 내용을 끼워 넣습니다

블록 참조는 인라인 칩으로 나타나고 `Cmd+클릭`으로 원본으로 이동합니다. 블록 임베드는 참조한 블록을 읽기 전용으로 실시간 표시하며 — 끼워 넣은 내용을 그 자리에서 편집할 수도 있고, 변경은 원본 파일로 반영됩니다.

**PDF 하이라이트 참조**도 블록 참조입니다. PDF 리더의 **참조 복사**가 만들어 줍니다. 인용한 문장으로 렌더되거나, 영역 하이라이트라면 잘라 낸 영역으로 렌더되며, 폭을 선택적으로 지정할 수 있습니다 — `((target#^id|w=60))`, 10부터 100까지의 정수 백분율이고 참조의 오른쪽 가장자리를 끌어서도 조정할 수 있습니다. [PDF 읽기와 하이라이트](/ko/docs/pdf/toolbar-zoom-and-find/)를 보십시오.

## 백링크

백링크 패널은 현재 파일로 링크하는 모든 문서를 보여 줍니다.

1. `Cmd+Shift+B`(macOS) 또는 `Ctrl+Shift+B`(Windows/Linux)를 눌러 백링크 사이드바를 엽니다
2. 백링크마다 원본 파일 이름과 주변 맥락이 보입니다
3. 백링크를 클릭하면 원본 파일로 이동합니다

**링크되지 않은 언급:** 백링크 아래의 별도 구역에는 현재 파일 이름을 본문에서 언급하지만 위키링크는 걸지 않은 파일이 나옵니다. 클릭하면 링크로 바꿉니다.

## 탐색 기록

최근에 다녀온 위치 사이를 오갑니다.

| 동작       | macOS          | Windows/Linux |
| ---------- | -------------- | ------------- |
| 뒤로 가기  | `Cmd+[`        | `Ctrl+[`      |
| 앞으로 가기 | `Cmd+]`       | `Ctrl+]`      |

## 북마크

자주 여는 파일을 북마크해 빠르게 엽니다.

1. `Cmd+D`(macOS) 또는 `Ctrl+D`(Windows/Linux)를 눌러 현재 파일을 북마크합니다
2. 북마크한 파일은 왼쪽 사이드바의 북마크 구역에 나타납니다
3. 다시 누르면 북마크가 해제됩니다

## 그래프 뷰

노트 연결을 시각적으로 보여 주는 지도입니다. 노드는 파일이고, 간선은 그 사이의 위키링크입니다. 그래프 뷰로 워크스페이스의 구조를 훑고 서로 관련된 노트의 뭉치를 발견할 수 있습니다.
