## 위키링크

`[[위키링크]]`로 노트를 잇습니다.

1. **`[[` 입력** — 맞는 파일이 뜨는 자동완성 팝업이 나타납니다
2. **파일 선택** — 위키링크가 삽입됩니다 (예: `[[내 노트]]`)
3. **Cmd+클릭** — 연결된 페이지로 이동합니다

**고급 위키링크 문법:**

| 문법                     | 설명                          |
| ------------------------ | ----------------------------- |
| `[[page]]`               | 페이지로 가는 기본 링크       |
| `[[page\|display text]]` | 표시 문구를 따로 둔 링크      |
| `[[page#heading]]`       | 특정 제목으로 가는 링크       |
| `[[page#^block-id]]`     | 특정 블록으로 가는 링크       |
| `[[paper.pdf]]`          | Baram이 볼 수 있는 마크다운 아닌 파일로 가는 링크 |

**다른 종류의 파일로 링크하기:** 확장자를 적으면 Baram이 문서로 여는 파일 — PDF, HTML,
코드 파일, 일반 텍스트(`.txt`·`.csv`·`.tsv`·`.log`) — 도 위키링크로 가리킬 수 있습니다.
예: `[[paper.pdf]]`, `[[schema.sql]]`. 자동완성은 이런 파일도 노트와 함께 보여 주면서 종류를
표시해, 고르기 전에 `report.pdf`와 `report.md`를 구별할 수 있습니다. 이미지와 SVG는 제시하지
않습니다 — 마크다운이 `![](…)`로 넣는 자산이기 때문입니다. 다만 `[[diagram.svg]]`를 직접 적으면
여전히 해석됩니다. 일반 마크다운 링크도 됩니다 —
`[그 논문](papers/attention.pdf)`은 파일을 운영체제에 넘기지 않고 Baram에서 엽니다.

링크 색인에 모이는 것은 `[[…]]` 링크뿐입니다. 그래서 인용한 PDF를 위키링크로 가리키면 백링크와
그래프 뷰에 나타나지만, 같은 파일을 평범한 마크다운 링크로 적으면 나타나지 않습니다.

**호버 미리보기:** 위키링크에 마우스를 올리면 페이지를 떠나지 않고 대상 문서의 내용을 미리 볼 수 있습니다.

## 자동 이름 변경

파일 트리에서 파일 이름을 바꾸면(파일을 선택하고 `F2`), 그 파일을 가리키는 위키링크가 워크스페이스 전체에서 자동으로 갱신됩니다.

## 태그

`#태그`로 노트를 정리하면 볼트 전체에서 색인됩니다.

1. 본문에 **`#태그`를 입력**하거나(자동완성이 기존 태그를 제안합니다), YAML 전문에 `tags:` 목록을 넣습니다
2. **중첩 태그** — `#부모/자식`으로 계층을 만듭니다
3. 태그를 **Cmd/Ctrl+클릭**하면 그 태그를 쓰는 모든 파일을 검색합니다

**태그 패널:** 활동 표시줄에서 태그 패널을 열면 태그를 트리로, 또는 빈도에 따라 크기가 달라지는 구름으로 훑어볼 수 있습니다. 여기서 할 수 있는 일:

- 볼트 전체에서 태그 **이름 바꾸기**
- 태그에 **색** 지정하기
- 태그로 **파일 트리 걸러 보기**
- 현재 노트에 대한 **AI 태그 제안** 받기
