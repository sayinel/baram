## 표

Baram은 GFM(GitHub Flavored Markdown) 파이프 표를 지원합니다.

**표 만들기:**

- **파이프 입력** — `| 헤더 1 | 헤더 2 |`를 입력하고 Enter를 누르면 헤더가 채워진 표가 자동으로 만들어집니다
- **격자 선택** — 슬래시 명령 `/table` 또는 `Cmd+T`로 10×10 격자에서 크기를 고릅니다
- **TSV 붙여넣기** — 탭으로 구분된 데이터(예: 스프레드시트)를 붙여넣으면 표가 자동으로 만들어집니다

**편집:**

- **Tab** / **Shift+Tab**으로 셀 사이를 이동합니다
- 열 정렬(`:---`, `:---:`, `---:`)이 유지됩니다
- **열 폭 조정** — 열 경계를 끌어 폭을 조정합니다(세션에만 남고 마크다운에는 저장되지 않습니다)
- 표에 마우스를 올리면 행·열을 추가하는 ⊕ 버튼이 보입니다
- **우클릭** 메뉴: 정렬, 헤더 전환, Markdown/HTML로 복사, 삭제

**셀 병합과 분할:**

- **셀 병합** — 여러 셀을 선택하고 `Cmd+M`(macOS) / `Ctrl+M`(Windows/Linux)을 누르거나, 우클릭해 "Merge Cells"를 선택합니다
- **셀 분할** — 병합된 셀에 커서를 두고 `Cmd+M`을 다시 누르거나, 우클릭해 "Split Cell"을 선택합니다
- **유지** — 셀 병합은 소스 모드 전환(`Cmd+/`)과 파일 재열기 후에도 유지됩니다. Baram은 파이프 표 안에 `<`와 `^` 표시를 써서 colspan·rowspan 정보를 담습니다:

```markdown
| 병합된 헤더   | <  | 보통   |
| ------------- | -- | ------ |
| 높은 셀       | A  | B      |
| ^             | C  | D      |
```

이 예에서 "병합된 헤더"는 2개 열에 걸치고(`<` 표시가 오른쪽으로 늘립니다), "높은 셀"은 2개 행에 걸칩니다(`^` 표시가 아래로 늘립니다). 이 표시는 Obsidian Sheets Extended와 호환되고, 다른 마크다운 뷰어에서는 그냥 텍스트로 보입니다.

## 목차

문서의 모든 제목을 자동으로 나열하는 목차를 넣습니다.

- 문단에 `[TOC]`를 입력하거나 슬래시 명령 `/toc`를 씁니다
- 제목을 추가·삭제·편집하면 목차가 실시간으로 갱신됩니다
- 항목을 클릭하면 그 제목으로 이동합니다
- 마크다운에는 `[TOC]`로 저장됩니다(Typora와 호환)
