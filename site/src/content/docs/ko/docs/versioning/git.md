Baram은 Git 저장소를 위한 소스 제어를 내장하고 있습니다.

## 소스 제어 사이드바

워크스페이스가 Git 저장소이면 왼쪽 사이드바에 **소스 제어** 구역이 나타납니다. 보여 주는 것:

- **변경된 파일** — 수정·추가·삭제된 파일과 상태 표시
- **스테이지 / 스테이지 해제** — `+` 또는 `-` 버튼으로 파일을 하나씩 스테이지하거나 해제합니다
- **커밋** — 커밋 메시지를 입력하고 커밋 버튼을 누릅니다
- **버리기** — 커밋하지 않은 변경을 되돌립니다

## Diff 뷰어

소스 제어 사이드바에서 변경된 파일을 클릭하면 diff를 봅니다. 추가는 초록, 삭제는 빨강으로 표시됩니다.

## 브랜치 관리

현재 브랜치는 에디터 아래 **상태바**에 표시됩니다. 클릭하면 브랜치를 바꾸거나 새로 만듭니다.

## 히스토리, 스태시, 원격

소스 제어 사이드바에는 탭이 셋 있습니다.

- **변경** — 스테이지·해제·커밋과 diff
- **히스토리** — 작성자·날짜·메시지가 있는 커밋 로그 훑어보기
- **스태시** — 작업 중인 변경을 저장해 두고 나중에 되살리기

원격 작업(Push, Pull, Fetch)은 저장소에 원격이 설정돼 있으면 헤더 바에서 쓸 수 있습니다.
