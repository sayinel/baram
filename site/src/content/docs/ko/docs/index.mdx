바람(Baram) 문서에 오신 것을 환영합니다. Baram은 AI 통합과 양방향 링크를 갖춘 가볍고
아름다운 WYSIWYG 마크다운 에디터이고, 아래 페이지들이 첫 문서를 쓰는 것부터 직접 만든
플러그인을 배포하는 것까지를 다룹니다.

## 여기서 시작

Baram이 처음이라면, 다음 순서가 빈 창에서 서로 이어진 노트 묶음까지 데려갑니다.

<Steps>

1. **[Baram 설치하기](/baram/ko/docs/getting-started/#설치)** — 사용하는 플랫폼의 빌드를
   내려받거나 소스에서 직접 빌드합니다.

2. **[폴더 열기](/baram/ko/docs/getting-started/#첫-실행)** — 마크다운 파일이 있는 폴더를
   Baram에 가리키거나 빈 문서로 시작합니다. 파일 트리가 왼쪽에 나타나고 오른쪽 사이드바는
   닫힌 채로 시작하므로, 창의 대부분이 글 쓰는 공간입니다.

3. **[첫 문서 쓰기](/baram/ko/docs/editing/files-and-tabs/)** — 파일과 탭, 그리고 입력을 멈춘
   뒤 곧 저장되는 자동 저장. 저장되기 전까지는 탭에 점이 표시됩니다.

4. **[키보드에서 손 떼지 않고 서식 넣기](/baram/ko/docs/editing/slash-commands-and-toolbars/)** —
   슬래시 명령으로 어떤 블록이든 넣고, 마크다운 문법은 커서가 떠나면 사라집니다.

5. **[노트를 서로 잇기](/baram/ko/docs/linking/wikilinks-and-tags/)** — 위키링크와 태그,
   백링크가 파일 더미를 돌아다닐 수 있는 것으로 바꿉니다.

6. **[그 폴더를 볼트로 만들기](/baram/ko/docs/workspace/vaults-and-approval/)** — 볼트는
   볼트 수준 설정과 자기 저널 디렉터리, 볼트 사이를 잇는 링크를 더해 줍니다.

7. **[AI 켜기](/baram/ko/docs/ai/setup-inline-and-ghost-text/)** *(선택)* — 쓰던 프로바이더와
   키를 그대로 가져오거나, Ollama로 전부 로컬에 둘 수 있습니다.

</Steps>

## 자주 찾는 것

- [**키보드 단축키**](/baram/ko/docs/customization/keyboard-shortcuts/) — Vim 모드까지 포함해
  한 페이지에 모은 전체 레퍼런스
- [**슬래시 명령**](/baram/ko/docs/editing/slash-commands-and-toolbars/) — `/`를 입력해 넣을 수
  있는 블록 전부
- [**쿼리 블록**](/baram/ko/docs/rich-content/query-blocks/) — 문서 안에 심어 두는, 살아 있는
  노트·태스크 목록
- [**태스크 패널**](/baram/ko/docs/tasks/panel-and-queries/) — 볼트 안의 모든 태스크를 걸러 봅니다
- [**내보내기**](/baram/ko/docs/export/) — HTML, PDF, Notion, Word, LaTeX, EPUB
