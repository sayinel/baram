Baram은 Claude, OpenAI, OpenRouter, Google Gemini, Ollama(로컬)로 동작하는 AI 글쓰기 지원을 내장하고 있습니다.

## 설정

1. `Cmd+,`(macOS) 또는 `Ctrl+,`(Windows/Linux)로 설정을 엽니다
2. **AI** 탭으로 갑니다
3. AI 프로바이더를 고릅니다(Claude, OpenAI, OpenRouter, Gemini, Ollama)
4. API 키를 입력합니다(프로바이더마다 자기 키 칸이 있고, Ollama는 키가 필요 없습니다)
5. 원하는 모델을 고릅니다(모델 목록은 프로바이더에서 실시간으로 불러옵니다)

## 개인정보 보호 모드

**설정 > AI**에서 개인정보 보호 모드를 켜면 문서 내용이 클라우드 AI 프로바이더로 전송되지 않습니다. 켜져 있는 동안에는 Ollama(로컬)만 허용됩니다.

전역으로 정할 수도 있고, YAML 전문으로 파일마다 정할 수도 있습니다.

```yaml
---
privacy: true
---
```

## 인라인 AI 편집 (`Cmd+J`)

`Cmd+J`(macOS) 또는 `Ctrl+J`(Windows/Linux)로 인라인 AI 프롬프트를 엽니다.

1. 지시를 입력합니다(예: "더 간결하게", "한국어로 번역")
2. AI가 요청을 처리하며 실시간으로 흘려보냅니다
3. **글자 단위 diff** 강조로 제안을 검토합니다:
   - 초록 = 추가
   - 빨강 = 삭제
4. **수락**을 눌러 적용하거나 **거부**로 버립니다

## 고스트 텍스트 (AI 자동완성)

입력하는 동안 커서 앞에 흐린 텍스트로 AI 자동완성 제안이 나타납니다.

| 동작                   | macOS       | Windows/Linux |
| ---------------------- | ----------- | ------------- |
| 제안 전체 수락         | `Tab`       | `Tab`         |
| 첫 단어만 수락         | `Cmd+Right` | `Ctrl+Right`  |
| 무시                   | `Escape`    | `Escape`      |

고스트 텍스트는 **설정 > AI**에서 켜고 끕니다.
