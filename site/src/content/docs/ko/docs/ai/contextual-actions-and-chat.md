## 상황별 AI 동작 (✨ 버튼)

AI 동작은 지금 다루는 내용에 맞춰 달라집니다. ✨ 버튼을 찾으십시오.

### 플로팅 툴바 (텍스트 선택)

텍스트를 선택하고 플로팅 툴바의 ✨ 버튼을 누르면 내용 종류에 맞는 동작이 나옵니다.

| 내용 종류     | 쓸 수 있는 동작                                                      |
| ------------- | -------------------------------------------------------------------- |
| **텍스트**    | 다듬기, 줄이기, 늘리기, 번역, 어조 바꾸기, 설명                      |
| **코드**      | 주석 달기, 최적화, 버그 찾기, 언어 변환, 테스트 생성                 |
| **수식**      | 풀이 보이기, LaTeX 고치기, 설명, 관련 공식                           |
| **표**        | 데이터 분석, 셀 채우기, 행 제안, CSV로                               |
| **구조**      | 목차 생성, 구조 다듬기, 구역 나누기, 요약                            |

### 블록 핸들 (⋮ 메뉴)

블록 왼쪽 가장자리 근처에 마우스를 올리면 ⋮ 핸들이 나옵니다. 그것을 클릭하고 ✨ 항목에 마우스를 올리면 블록 수준의 AI 동작에 닿습니다. 동작은 그 블록의 내용 종류에 자동으로 맞춰집니다.

### NodeView AI 버튼

특수 블록에 마우스를 올리면 블록 위에 바로 ✨ 버튼이 나옵니다.

- **코드 블록** — 주석 달기, 최적화, 버그 찾기, 변환, 테스트 생성
- **수식 블록** — 풀이 보이기, LaTeX 고치기, 설명, 관련 공식
- **표** — 데이터 분석, 셀 채우기, 행 제안, CSV로
- **이미지** — 대체 텍스트 생성, 설명문 생성, 묘사
- **Mermaid 다이어그램** — 다이어그램 다듬기, 설명, 노드 제안, 스타일 바꾸기, 종류 변환
- **콜아웃** — 다듬기, 줄이기, 늘리기, 번역

## AI 채팅 패널

`Cmd+Shift+A`(macOS) 또는 `Ctrl+Shift+A`(Windows/Linux)로 AI 채팅 패널을 엽니다.

**@참조**로 맥락을 주면서 문서에 대해 AI와 대화합니다.

| 참조         | 설명                                  |
| ------------ | ------------------------------------- |
| `@selection` | 에디터에서 현재 선택한 텍스트         |
| `@current`   | 현재 파일의 전체 내용                 |
| `@file`      | 워크스페이스의 아무 파일 내용         |
| `@clipboard` | 현재 클립보드 내용                    |

채팅 패널은 마크다운 렌더와 함께 응답을 흘려보냅니다. **에디터에 적용**을 쓰면 AI 응답을 서식이 갖춰진 WYSIWYG 내용으로 에디터에 바로 넣습니다.
