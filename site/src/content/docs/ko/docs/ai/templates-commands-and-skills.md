## 스마트 템플릿

슬래시 메뉴에서 `/ai-template`을 입력하면 AI 템플릿으로 구조가 갖춰진 내용을 만듭니다.

- 템플릿 분류에서 고릅니다(예: 회의록, 프로젝트 계획, 기술 명세)
- 또는 어떤 문서 종류든 직접 설명을 씁니다
- 만들어진 내용은 완전히 렌더된 WYSIWYG 블록(제목, 목록, 표 등)으로 들어갑니다

## 슬래시 AI 명령어

에디터에서 `/`를 입력하면 AI 명령어에 닿습니다.

| 명령어            | 설명                                   |
| ----------------- | -------------------------------------- |
| `/ai-write`       | 현재 맥락에서 쓰거나 이어 씁니다       |
| `/ai-brainstorm`  | 현재 맥락에서 아이디어를 냅니다        |
| `/ai-summarize`   | 선택한 텍스트를 요약합니다             |
| `/ai-expand`      | 선택한 텍스트를 늘려 설명합니다        |
| `/ai-fix-grammar` | 문법과 맞춤법을 고칩니다               |
| `/ai-translate`   | 다른 언어로 번역합니다                 |
| `/ai-explain`     | 선택한 텍스트를 쉬운 말로 설명합니다   |
| `/ai-template`    | AI 템플릿으로 내용을 만듭니다          |
| `/extract-tasks`  | 선택 영역에서 할 일을 뽑아냅니다       |

## 할 일 뽑아내기

`/extract-tasks`(**할 일 뽑아내기**)는 선택한 산문 — 회의록, 통화 요약, 결정 사항 문단 — 을 읽고 거기서 태스크를 뽑아 제안합니다.

1. 텍스트를 선택합니다(또는 읽히고 싶은 구역에 커서를 둡니다)
2. 슬래시 메뉴에서 `/extract-tasks`를 실행합니다
3. AI diff 미리보기에서 제안된 태스크 줄을 검토합니다
4. **수락**하면 들어가고 **거부**하면 버려집니다

수락하기 전까지 문서에는 아무것도 쓰이지 않습니다. 뽑아낸 줄은 평범한 태스크 줄이므로, 날짜와 우선순위는 나중에 여느 때처럼 붙일 수 있습니다 — [태스크](/ko/docs/tasks/anatomy-and-typing/) 참조.

설정된 AI 모델이 필요하고, [개인정보 보호 모드](/ko/docs/ai/setup-inline-and-ghost-text/#개인정보-보호-모드)를 존중합니다. 보호 모드가 켜져 있고 로컬 모델이 없으면, 노트를 클라우드 프로바이더로 보내지 않고 거절합니다.

## 커스텀 AI 명령어

**설정 > AI > 커스텀 명령어**에서 직접 슬래시 명령어를 만듭니다.

- 이름, 설명, 프롬프트 템플릿을 정합니다
- 변수 치환을 씁니다: `{selection}`, `{document}`, `{clipboard}`
- 커스텀 명령어는 내장 AI 명령어와 나란히 슬래시 메뉴에 나타납니다

## Skills

Baram에는 AI 프롬프트 파일(Skills)을 편집하는 도구가 있습니다.

- **프롬프트 린트** — 정적 규칙 6개가 흔한 문제를 검사합니다(물결 밑줄로 표시)
- **스킬 템플릿** — 흔한 프롬프트 패턴을 미리 만들어 둔 템플릿에서 시작합니다
- **스킬 자동 생성** — 원하는 것을 설명하면 AI가 스킬 파일을 만듭니다
- **스킬 테스트**(`Cmd+Shift+T` / `Ctrl+Shift+T`) — 스킬을 AI 프로바이더로 실제 실행해 그 자리에서 시험합니다
