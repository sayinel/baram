## 버전 히스토리 (파일 스냅샷)

### 버전 히스토리가 무엇인가요?

Baram은 바뀐 `.md` 파일의 스냅샷을 일정 간격으로 자동 저장합니다(기본: 30분마다). Git과 무관한 안전망이라, 지난 버전을 훑어보고 diff를 확인하고 언제든 파일을 되돌릴 수 있습니다.

### 버전 히스토리를 어떻게 여나요?

활동 표시줄(왼쪽 사이드바)의 **시계 아이콘**을 클릭하면 버전 히스토리 패널이 열립니다. 모든 스냅샷의 타임라인을 보여 줍니다.

### 수동 스냅샷은 어떻게 만드나요?

버전 히스토리 패널 헤더의 **+** 버튼을 클릭합니다. 라벨(예: "리팩터링 전")을 붙일 수 있습니다. 라벨이 있는 수동 스냅샷은 자동으로 지워지지 않습니다.

### 스냅샷에서 파일을 어떻게 복원하나요?

1. 타임라인의 스냅샷을 클릭해 파일 목록을 봅니다
2. 복원할 파일을 체크합니다(또는 "모두 복원"을 씁니다)
3. **복원**을 클릭합니다 — Baram이 현재 상태를 먼저 저장하므로 복원 자체도 되돌릴 수 있습니다

### 스냅샷과 현재 파일의 diff는 어떻게 보나요?

타임라인의 스냅샷을 클릭한 뒤 파일 이름을 클릭합니다. 추가(초록)와 삭제(빨강)를 보여 주는 한 줄씩 비교가 나옵니다.

### 스냅샷은 얼마나 오래 보관되나요?

시간이 지나면 자동으로 솎아 냅니다 — 최근 24시간은 전부, 1~7일은 시간당 하나, 7~30일은 하루당 하나, 30일 이후는 주당 하나. 기본 한도는 스냅샷 50개와 총 500MB입니다. 라벨이 있는 수동 스냅샷은 자동으로 지워지지 않습니다.

### 자동 스냅샷을 끌 수 있나요?

네. **설정 > 일반**으로 가서 **스냅샷 간격**을 0분으로 두십시오.

### 버전 히스토리는 Git과 어떻게 다른가요?

버전 히스토리는 자동이고 파일 수준입니다 — 커밋이나 메시지 없이 바뀐 파일을 조용히 저장합니다. Git은 의도적이고 의미 중심입니다 — 언제 무엇을 커밋할지 사람이 정합니다. 두 시스템은 서로 무관하게 동작하고, 커밋을 선호하는 Git 사용자는 스냅샷을 끌 수 있습니다.

## Git 연동

### Baram이 Git을 지원하나요?

네. 워크스페이스가 Git 저장소이면 왼쪽 사이드바에 **소스 제어** 구역이 나타납니다. 에디터를 떠나지 않고 변경 보기, 파일 스테이지·해제, 커밋 메시지 쓰기, diff 보기, 브랜치 전환을 할 수 있습니다.

### 변경을 어떻게 커밋하나요?

소스 제어 사이드바를 열고 커밋할 파일을 스테이지한 뒤(`+` 버튼 클릭), 커밋 메시지를 입력하고 커밋 버튼을 클릭합니다.

### 브랜치를 어떻게 바꾸나요?

에디터 아래 상태바의 브랜치 이름을 클릭합니다. 드롭다운이 나와 기존 브랜치로 바꾸거나 새로 만들 수 있습니다.

## 내보내기

### 어떤 내보내기 형식을 지원하나요?

일곱 가지를 지원합니다.

- **HTML** — 인라인 스타일, 수식 렌더, 코드 강조가 담긴 그 자체로 완결된 HTML
- **PDF** — 시스템 인쇄 대화상자를 거친 인쇄용 PDF
- **Notion** — Baram 고유 문법을 변환한 Notion 호환 마크다운
- **Word(DOCX)** — Pandoc을 거친 편집 가능한 Word 문서, 템플릿 선택 가능
- **LaTeX** — Pandoc을 거친 학술·과학 문서용 조판 형식
- **EPUB** — Pandoc을 거친 전자책 형식
- **RST** — Pandoc을 거친 Sphinx 문서용 reStructuredText

뒤의 네 형식은 [Pandoc](https://pandoc.org/) 설치가 필요합니다.

### 문서를 어떻게 내보내나요?

**파일 > 내보내기**로 내보내기 대화상자를 엽니다. 원하는 형식을 고르고 제목을 입력한 뒤 내보내기를 클릭합니다. 명령 팔레트(`Cmd+Shift+P`)에서 "Export"를 검색해도 됩니다.

### Pandoc이 무엇이고 꼭 필요한가요?

[Pandoc](https://pandoc.org/)은 무료 문서 변환기입니다. Word, LaTeX, EPUB, RST로 내보내려는 경우에만 필요합니다. Baram이 Pandoc을 자동으로 찾습니다 — 설치돼 있으면 내보내기 대화상자에서 Pandoc 형식을 쓸 수 있고, 없으면 그 형식들이 흐리게 표시됩니다.

### Pandoc은 어떻게 설치하나요?

플랫폼별 안내는 [pandoc.org/installing.html](https://pandoc.org/installing.html)을 보십시오. macOS: `brew install pandoc`. Windows: 인스톨러를 내려받습니다. Linux: `apt install pandoc` 또는 그에 해당하는 명령.

### DOCX 내보내기에 Word 템플릿을 쓸 수 있나요?

네. 내보내기 대화상자에서 Word 형식을 고르면 템플릿 선택기가 나옵니다. `.docx` 참조 템플릿을 고르면 Pandoc이 그 스타일(제목, 글꼴, 색, 머리글·바닥글)을 내보낸 문서에 적용합니다.

### "Notion으로 내보내기"는 무엇을 변환하나요?

Notion이 바로 가져올 수 없는 Baram 고유 마크다운 문법을 자동으로 변환합니다 — `[[위키링크]]`는 표준 `[링크](url)`로, 콜아웃은 이모지를 앞에 붙인 인용문으로, 인라인 수식 `$...$`는 블록 수식 `$$...$$`로, 강조 `==text==`는 굵게로, 아래·위 첨자는 유니코드 문자나 수식으로, 각주는 Notes 구역이 있는 인라인 참조로 바뀝니다.

### 내보낼 때 이미지가 포함되나요?

URL로 참조한 이미지는 HTML 내보내기에 링크로 포함됩니다. PDF 내보내기에서는 시스템 인쇄 엔진이 이미지를 렌더합니다.

### 도움말 패널은 어디 있나요?

이제 없습니다. **도움말** 메뉴를 열어 **사용 설명서**, **키보드 단축키**, **FAQ**를 고르십시오 — 앱 안 패널이 아니라 브라우저에서 해당 페이지가 열립니다.
