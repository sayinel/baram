## 위키링크는 어떻게 동작하나요?

`[[`를 입력하면 위키링크가 시작됩니다. 워크스페이스에서 맞는 파일이 뜨는 자동완성 팝업이 나옵니다. 파일을 고르면 `[[내 노트]]` 같은 링크가 들어갑니다. Cmd+클릭(Windows는 Ctrl+클릭)으로 연결된 페이지로 이동합니다.

고급 문법:

- `[[page|보일 텍스트]]` — 표시 문구를 따로 둡니다
- `[[page#heading]]` — 특정 제목으로 링크합니다
- `[[page#^block-id]]` — 특정 블록으로 링크합니다
- `[[paper.pdf]]` — Baram이 볼 수 있는 마크다운 아닌 파일로 링크합니다

확장자를 적으면 Baram이 앱 안에서 여는 파일 — PDF, HTML, 이미지, SVG — 도 위키링크로 가리킬 수
있습니다. 자동완성이 그런 파일도 제시하면서 종류를 표시하므로, 고르기 전에 `report.pdf`와
`report.md`를 구별할 수 있습니다. `[그 논문](papers/attention.pdf)` 같은 평범한 마크다운 링크도
Baram에서 열리고, 이 모두가 보통 링크와 똑같이 색인되므로 백링크와 그래프 뷰에 나타납니다.

## 백링크가 무엇인가요?

백링크는 위키링크의 반대입니다 — 어떤 문서가 현재 파일*로* 링크하는지 보여 줍니다. `Cmd+Shift+B`로 사이드바의 백링크 패널을 엽니다. 백링크마다 원본 파일과 맥락이 보입니다.

## 링크되지 않은 언급이 무엇인가요?

링크되지 않은 언급은 현재 파일 이름을 본문에 담고 있지만 실제 `[[위키링크]]`는 없는 파일을 보여 줍니다. 정식으로 이어 두고 싶은 연결을 발견하는 데 도움이 됩니다.

## 블록 참조와 블록 임베드가 무엇인가요?

- **블록 참조** `((file#^id))` — 다른 파일의 특정 블록을 가리키는 인라인 참조. Cmd+클릭으로 이동합니다.
- **블록 임베드** `{{embed ((file#^id))}}` — 참조한 블록을 실시간으로 끼워 넣습니다. 끼워 넣은 내용을 그 자리에서 편집할 수 있습니다.

참조할 수 있는 블록을 만들려면 문단이나 제목 끝에 `^my-id`를 붙입니다.

## @언급은 무엇이고 위키링크와 어떻게 다른가요?

@언급(`@[[page]]`)과 위키링크(`[[page]]`)는 둘 다 워크스페이스의 페이지로 링크하지만 목적이 다릅니다.

- **위키링크**(`[[page]]`)는 서식이 붙은 인라인 텍스트 링크로 렌더됩니다 — 흐르는 산문에 좋습니다
- **언급**(`@[[page]]`)은 아이콘이 붙은 칩 배지로 렌더됩니다(날짜는 📅, 페이지는 📄) — 빠르게 훑기에 시각적으로 뚜렷합니다

`@`를 입력하면 위에 빠른 날짜(오늘, 어제, 내일)가, 아래에 워크스페이스 페이지가 있는 언급 팝업이 열립니다. 언급은 특히 날짜(저널 항목)를 참조할 때, 그리고 더 눈에 띄는 표시를 원할 때 좋습니다.

마크다운에서 언급은 `@[[value]]`로 저장됩니다 — 앞의 `@`가 보통 위키링크와 구별해 줍니다.

## 태그는 어떻게 동작하나요?

본문에 `#태그`를 입력하거나(자동완성이 됩니다) YAML 전문에 `tags:` 목록을 넣습니다 — 둘 다 볼트 전체에서 색인됩니다. `#부모/자식`으로 중첩 태그를 만듭니다. 태그를 `Cmd/Ctrl+클릭`하면 그것을 쓰는 모든 파일을 검색합니다. (활동 표시줄의) 태그 패널은 트리나 빈도에 따라 크기가 달라지는 구름을 보여 주고, 여기서 볼트 전체에서 태그 이름을 바꾸고, 색을 지정하고, 태그로 파일 트리를 걸러 보고, 현재 노트에 대한 AI 태그 제안을 받을 수 있습니다.

## 파일 이름을 바꾸면 어떻게 되나요?

파일 트리에서 파일 이름을 바꾸면(`F2`), 그 파일을 가리키는 위키링크가 워크스페이스 전체에서 자동으로 갱신됩니다. 깨진 링크가 없습니다.

## 최근에 본 파일 사이를 어떻게 오가나요?

`Cmd+[`(macOS) 또는 `Ctrl+[`(Windows/Linux)로 뒤로, `Cmd+]` / `Ctrl+]`로 앞으로 갑니다. 브라우저 탐색 기록처럼 동작합니다.

## 파일을 어떻게 북마크하나요?

`Cmd+D`(macOS) 또는 `Ctrl+D`(Windows/Linux)로 현재 파일을 북마크합니다. 북마크한 파일은 왼쪽 사이드바의 북마크 구역에 나타납니다. 다시 누르면 해제됩니다.

## 파일 사이를 빠르게 오가려면?

`Cmd+K`(macOS) 또는 `Ctrl+K`(Windows/Linux)로 빠른 전환을 엽니다. 입력해 파일 이름으로 검색하고, `#`을 입력하면 제목으로 검색합니다. `Ctrl+Tab`으로 최근 사용 순서(MRU) 탭 전환도 됩니다.
