## API 키는 어디서 받나요?

Baram은 여러 AI 프로바이더를 지원합니다. 해당 프로바이더에서 API 키를 받으십시오.

| 프로바이더             | 키를 받는 곳                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| **Claude**(Anthropic)  | [console.anthropic.com](https://console.anthropic.com/)              |
| **OpenAI**             | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |
| **OpenRouter**         | [openrouter.ai/keys](https://openrouter.ai/keys)                     |
| **Google Gemini**      | [aistudio.google.com/apikey](https://aistudio.google.com/apikey)     |
| **Ollama**(로컬)       | API 키가 필요 없습니다 — 내 기기에서 돕니다                          |

프로바이더마다 **설정 > AI**에 자기 API 키 칸이 있습니다.

**OpenRouter**는 모델 공급사가 아니라 게이트웨이입니다. 키 하나로 여러 공급사의 모델에 닿고, 모델은 공급사가 앞에 붙은 id(`anthropic/claude-sonnet-4.5`, `openai/gpt-4o`)로 고르거나 `openrouter/auto`에 맡깁니다. 요청이 OpenRouter를 거치므로 무엇이 보관되는지는 Baram이 아니라 OpenRouter 계정 설정이 정합니다.

## 어떤 AI 모델을 지원하나요?

Baram은 고른 프로바이더에서 쓸 수 있는 모델을 실시간으로 불러옵니다. **설정 > AI**로 가서 프로바이더를 고르면, 모델 드롭다운이 그 프로바이더에서 쓸 수 있는 모델을 보여 줍니다.

## AI 사용료는 얼마인가요?

AI 사용료는 API 프로바이더가 청구합니다. Baram 자체는 AI 기능에 요금을 매기지 않습니다 — 프로바이더의 가격에 따라 API 호출분만 지불합니다. **Ollama**는 모델을 내 기기에서 돌리므로 무료입니다.

## 인라인 AI 편집은 어떻게 쓰나요?

`Cmd+J`(macOS) / `Ctrl+J`(Windows/Linux)로 인라인 AI 프롬프트를 엽니다. 자연어로 지시를 입력하고(예: "영어로 번역", "문법 고치기"), diff를 검토한 뒤(초록 = 추가, 빨강 = 삭제) 변경을 수락하거나 거부합니다.

## ✨ 버튼이 무엇인가요?

✨ 버튼은 지금 다루는 내용에 맞춰 달라지는 상황별 AI 동작을 제공합니다. 세 곳에 나타납니다.

1. **플로팅 툴바** — 텍스트를 선택하고 ✨를 클릭하면 텍스트에 맞는 동작이 나옵니다(다듬기, 줄이기, 번역 등)
2. **블록 핸들** — 블록 왼쪽 가장자리 근처에 마우스를 올리고 ⋮를 클릭한 뒤 ✨에 마우스를 올리면 블록 수준 동작이 나옵니다
3. **NodeView 버튼** — 코드 블록·수식 블록·표·이미지·콜아웃·Mermaid 다이어그램에 마우스를 올리면 특화된 동작이 있는 ✨ 버튼이 보입니다(예: 코드는 "버그 찾기", 수식은 "LaTeX 고치기")

## 스마트 템플릿이 무엇인가요?

슬래시 메뉴에서 `/ai-template`을 입력하면 AI가 구조 있는 문서를 만들어 줍니다. 미리 준비된 템플릿(회의록, 프로젝트 계획 등)을 고르거나 직접 설명을 씁니다. AI가 서식이 갖춰진 내용(제목, 목록, 표)을 만들어 WYSIWYG 블록으로 바로 넣습니다.

## 고스트 텍스트가 무엇인가요?

고스트 텍스트는 입력하는 동안 커서 앞에 흐린 텍스트로 제안을 보여 주는 AI 자동완성입니다. `Tab`으로 제안 전체를, `Cmd+Right`(macOS) / `Ctrl+Right`(Windows/Linux)로 첫 단어만 수락하고, `Escape`로 무시합니다. **설정 > AI**에서 켜고 끕니다.

## AI 채팅 패널이 무엇인가요?

`Cmd+Shift+A`(macOS) 또는 `Ctrl+Shift+A`(Windows/Linux)로 문서에 대해 AI와 대화하는 채팅 패널을 엽니다. `@참조`로 맥락을 줍니다 — `@selection`(선택한 텍스트), `@current`(현재 파일), `@file`(아무 파일), `@clipboard`(클립보드 내용). **에디터에 적용**으로 AI 응답을 서식이 갖춰진 내용으로 문서에 바로 넣습니다.

## 커스텀 AI 명령어가 무엇인가요?

**설정 > AI > 커스텀 명령어**에서 다시 쓸 수 있는 AI 명령어를 직접 만듭니다. 명령어마다 이름, 설명, 그리고 변수 치환이 되는 프롬프트 템플릿(`{selection}`, `{document}`, `{clipboard}`)을 갖습니다. 커스텀 명령어는 내장 AI 명령어와 나란히 슬래시 메뉴에 나타납니다.

## 슬래시 AI 명령어가 무엇인가요?

`/`를 입력해 슬래시 메뉴를 열고 AI 구역으로 내려가거나, `/ai-`를 입력해 걸러 봅니다. 쓸 수 있는 명령어: write, brainstorm, summarize, expand, fix grammar, translate, explain, 스마트 템플릿. 커스텀 AI 명령어도 여기 나타납니다.

## 데이터를 클라우드로 보내지 않고 AI를 쓸 수 있나요?

네. 프로바이더로 **Ollama**를 고르고 **설정 > AI**에서 **개인정보 보호 모드**를 켜십시오. Ollama는 모델을 내 기기에서 돌리므로 컴퓨터 밖으로 데이터가 나가지 않습니다. 개인정보 보호 모드가 켜져 있으면 Ollama만 허용됩니다.

## 개인정보 보호 모드가 무엇인가요?

켜 두면 문서 내용이 클라우드 AI 프로바이더로 전송되지 않습니다. Ollama(로컬)만 허용됩니다. **설정 > AI**에서 전역으로 켜거나, YAML 전문에 `privacy: true`를 넣어 파일마다 켭니다.

## 텍스트를 어떻게 찾고 바꾸나요?

`Cmd+F`(macOS) / `Ctrl+F`(Windows/Linux)로 찾기를 엽니다. `Cmd+H` / `Ctrl+H`로 찾기 및 바꾸기를 엽니다. `Enter` / `Shift+Enter`로 결과를 오갑니다. 하나씩 또는 전부 바꿉니다.

## AI 기능이 동작하지 않습니다. 무엇을 확인할까요?

1. **API 키** — **설정 > AI**에서 고른 프로바이더의 유효한 API 키를 넣었는지 확인하십시오
2. **프로바이더** — 맞는 프로바이더가 골라져 있는지 확인하십시오
3. **네트워크** — 클라우드 프로바이더(Claude, OpenAI, OpenRouter, Gemini)는 인터넷이 필요하고, Ollama는 로컬에서 돌고 있어야 합니다
4. **모델 선택** — 유효한 모델이 골라져 있는지 확인하십시오
5. **개인정보 보호 모드** — 켜져 있으면 Ollama만 동작합니다. 뜻하지 않게 켜져 있지 않은지 확인하십시오
