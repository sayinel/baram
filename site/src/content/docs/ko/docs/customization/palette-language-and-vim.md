## 명령 팔레트

`Cmd+Shift+P`(macOS) 또는 `Ctrl+Shift+P`(Windows/Linux)로 명령 팔레트를 엽니다. 입력해서 어떤 명령·설정·동작이든 찾을 수 있습니다. Baram의 기능에 닿는 가장 빠른 길입니다.

## 언어

Baram은 영어와 한국어 인터페이스를 지원합니다.

1. **설정 > 언어**를 엽니다(`Cmd+,` 후 언어 탭 선택)
2. 원하는 언어를 고릅니다
3. UI 전체가 즉시 바뀝니다 — 메뉴, 대화상자, 설정, 시작 화면

지원하는 언어라면 시스템 언어를 기본값으로 쓰고, 아니면 영어를 씁니다.

## Vim 모드

**설정 > 에디터 > Vim 키 바인딩**을 켜면(기본은 꺼짐) 모달 편집이 됩니다. 스위치 하나가 세 표면을 덮습니다.

- **소스 모드**와 **코드 파일** — 완전한 vim. 텍스트 오브젝트, `.` 반복, `/` 검색, 매크로, 레지스터까지
- **WYSIWYG** — 렌더된 문서에서의 모달 편집: 이동, 횟수를 붙인 오퍼레이터, `f`/`t` 찾기, `/` 검색, 비주얼·비주얼 라인 모드, `zz`, `Space`로 태스크 전환, `:w` / `:q` / `:N` 줄 이동. 텍스트 오브젝트와 `.` 반복, 마크는 아직 없습니다
- **문서 안의 코드 블록** — 완전한 vim. `j`/`k`와 방향키가 블록 안팎을 넘나들고, 노멀 모드에서 `Esc`를 누르면 문서로 돌아오며, 키보드로 움직이든 마우스로 움직이든 모드(노멀 또는 인서트)가 경계를 넘어 커서를 따라갑니다
- **수식·Mermaid·SVG·HTML·쿼리 블록** — 선택한 블록에서 `i`를 누르면 그 편집기가 열리고, `Esc`로 블록으로 돌아옵니다

상태바가 현재 모드(`-- NORMAL --`, `-- INSERT --`, `-- VISUAL --`, 또는 블록 편집기가 키를 잡고 있을 때 `-- INSERT (math) --`)를 보여 주고, `:`과 `/` 명령줄 역할도 합니다. Vim 명령은 한글 IME가 켜져 있어도 동작합니다 — 노멀 모드에서 키는 물리적 위치로 해석되므로, `ㅓ`가 입력될 자리에서도 `j`는 아래로 움직입니다.

Vim 키 시퀀스는 앱 단축키와 별개 계층이고 설정 > 키 바인딩에서 재지정할 수 없습니다.

> 📖 전체 명령 목록은 [키보드 단축키 레퍼런스](/ko/docs/customization/keyboard-shortcuts/#vim-모드)에 있습니다.

## 키보드 단축키

모든 키보드 단축키는 **설정 > 키 바인딩**에서 조정할 수 있습니다.

1. 이름이나 키 조합으로 단축키를 검색합니다
2. 단축키의 **편집**을 클릭해 새 키 조합 입력을 시작합니다
3. 원하는 키를 누릅니다 — 충돌하면 그 조합을 이미 쓰는 명령이 무엇인지 Baram이 알려 줍니다
4. **적용**을 눌러 확정하거나 **취소**로 현재 설정을 유지합니다
5. 초기화 버튼을 누르면 그 단축키 하나만 기본값으로 돌아갑니다

아래쪽의 **모두 초기화**로 전체 단축키를 기본값으로 되돌립니다.

쓸 수 있는 단축키 전체는 [키보드 단축키 레퍼런스](/ko/docs/customization/keyboard-shortcuts/)를 보십시오.
