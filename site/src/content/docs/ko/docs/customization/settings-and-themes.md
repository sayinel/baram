## 설정

`Cmd+,`(macOS) 또는 `Ctrl+,`(Windows/Linux)로 설정을 엽니다.

설정 탭은 이렇게 그룹으로 나뉩니다.

| 그룹         | 탭               | 조정할 수 있는 것                                                    |
| ------------ | ---------------- | --------------------------------------------------------------------------------------------------- |
| **일반**     | **일반**         | 시작 동작, 자동 저장, 링크, 파일 스냅샷, 업데이트                    |
| **일반**     | **에디터**       | 글꼴, 입력 동작, Vim 모드, 에디터 폭                                 |
| **일반**     | **외관**         | 테마 갤러리, 사용자 테마, 레이아웃 프리셋                            |
| **일반**     | **마크다운**     | 직렬화 규칙                                                          |
| **일반**     | **언어**         | 인터페이스 언어                                                      |
| **일반**     | **단축키**       | 단축키 조정                                                          |
| **기능**     | **저널**         | 저널 활성화, 디렉터리, 템플릿, 주기 노트                             |
| **기능**     | **Zettel**       | Zettel 활성화, 디렉터리, 시작 동작, 홈 노트                          |
| **기능**     | **태스크**       | 태스크 활성화, 태스크 홈, 캡처, 아젠다 범위                          |
| **기능**     | **AI**           | AI 활성화, 제공자, 모델, 프라이버시, 고스트 텍스트                   |
| **시스템**   | **활동 표시줄**  | 표시할 아이콘과 그 순서                                              |
| **시스템**   | **플러그인**     | 플러그인 설치·활성화·설정                                            |
| **시스템**   | **볼트**         | 볼트 초기화, 승인된 폴더                                             |

각 기능 탭(저널, Zettel, 태스크, AI)은 맨 위에 **활성화** 토글이 있습니다. 기능을 끄면 탭이 사라지지 않고 흐려지며, 언제든 다시 켤 수 있습니다.

기능을 끄면 그 기능이 가진 화면도 함께 사라집니다 — 활동 표시줄 아이콘, 슬래시 메뉴 그룹, 명령 팔레트 항목이 모두 없어지고 AI는 ✨ 버튼까지 함께 사라집니다. 단축키는 그대로 남습니다. 누르면 아무 일도 일어나지 않는 대신 기능이 꺼져 있다고 알려 줍니다.

## 테마

Baram은 내장 테마 8개와 함께 오고, 사용자 테마도 만들 수 있습니다.

**내장 테마:**

| 테마               | 스타일                                 |
| ------------------ | -------------------------------------- |
| Default Light      | 깔끔한 라이트 테마(기본값)             |
| Default Dark       | 파란 톤의 다크 테마                    |
| Tokyo Night        | 널리 쓰이는 다크 테마, 차가운 파란 팔레트 |
| Solarized Light    | Ethan Schoonover의 따뜻한 라이트 팔레트 |
| Solarized Dark     | Ethan Schoonover의 다크 팔레트         |
| Nord               | 북극에서 영감을 얻은 다크 테마         |
| Baram Garden Light | 따뜻한 정원풍 라이트 테마              |
| Baram Garden Dark  | 따뜻한 정원풍 다크 테마                |

**테마 쓰기:**

1. **설정 > 외관**을 열어 테마 갤러리를 봅니다
2. 테마 카드를 클릭하면 즉시 적용됩니다
3. **시스템(자동)**을 고르면 OS의 라이트·다크 모드를 따릅니다

**사용자 테마 만들기:**

1. 외관 탭에서 **사용자 지정...**을 클릭합니다
2. 테마 이름을 정하고 기준 모드(라이트 또는 다크)를 고릅니다
3. 색 선택기로 색 값 25개를 조정합니다(배경·텍스트·테두리·강조색·에디터·상태·그래프로 묶여 있습니다)
4. 고르는 즉시 색이 반영됩니다 — 실시간으로 미리 봅니다
5. **저장**을 누르면 테마가 남고, **취소**를 누르면 버립니다

**가져오기 / 내보내기:**

- **테마 가져오기...**를 클릭해 `.json` 테마 파일을 불러옵니다
- 테마 편집기에서 **내보내기**를 클릭하면 현재 테마를 공유용 `.json` 파일로 저장합니다

## 글꼴

글꼴은 **설정 > 에디터**의 **글꼴** 항목에 있습니다. 에디터를 바꾸는 설정이고, 앱 자체의
인터페이스는 바뀌지 않습니다.

Baram은 서체 두 벌을 함께 배포합니다. 그래서 같은 문서가 macOS·Windows·Linux에서 같게
보입니다 — 본문은 **Pretendard Variable**, 코드는 **JetBrains Mono Variable**입니다. 둘 다
SIL Open Font License 1.1이며, **Baram > Baram에 대하여 > 기본 제공 서체 >
서체 라이선스 보기**에서 전문을 볼 수 있습니다.

### 두 개의 슬롯

| 슬롯     | 설정          | 적용 범위                        |
| -------- | ------------- | -------------------------------- |
| **본문** | **글꼴**      | 에디터 본문 텍스트               |
| **코드** | **코드 서체** | 코드 블록, 수식, 인라인 코드     |

각 슬롯은 현재 서체를 실제 크기의 미리보기 띠와 함께 보여 주고, 그 서체가 어디서 온
것인지를 배지로 알려 줍니다.

| 배지               | 뜻                                                                            |
| ------------------ | ----------------------------------------------------------------------------- |
| **기본 제공**      | Baram이 함께 배포하는 서체라 어느 머신에서나 있습니다                          |
| **시스템**         | 이 머신에 설치된 서체입니다(한글까지 담고 있으면 **시스템 · 한글**)            |
| **이 머신에 없음** | 이름은 저장돼 있지만 여기서는 그릴 수 없어 다른 서체로 대체돼 보입니다         |

이 배지가 행의 존재 이유입니다. 설치되지 않은 서체도 대체 서체로 그려지기 때문에, 배지가
없던 시절에는 잘못 고른 값이 정상처럼 보였습니다.

### 서체 브라우저

서체 이름이나 **더 보기**를 누르면 2단 브라우저가 열립니다. **본문**·**코드** 탭으로 브라우저를
벗어나지 않고 슬롯을 옮길 수 있습니다.

왼쪽에는 서체가 **기본 제공** · **최근 사용** · **설치된 서체** 세 그룹으로, 각각 자기 서체로
이름이 그려집니다. **서체 검색…**으로 이름을 좁히면 전체 중 몇 종이 남았는지 숫자가 알려
줍니다. **한글**·**고정폭** 칩으로 더 좁힐 수 있습니다. 코드 슬롯에서는 고정폭 칩이 처음부터
켜져 있습니다 — 그 슬롯은 기본이 고정폭이기 때문입니다. 그래서 거기서는 칩을 **끄는** 것이
목록을 모든 서체로 넓힙니다. 서체를 새로 설치했다면 **새로고침**이 목록을 다시 읽고, 목록을
아예 읽지 못하면 빈 화면 대신 그 사실을 알리고 기본 제공 서체를 보여 줍니다.

오른쪽은 본문과 코드를 함께 미리 보여 줍니다 — 영문·한글, 그리고 서체마다 가장 많이
갈리는 글자들입니다. 크기·줄 높이 슬라이더도 설정 행과 같은 것이 붙어 있습니다. 설정이
둘인 게 아니라 하나를 두 곳에서 조절하는 것입니다.

Baram이 찾지 못한 서체를 쓰려면 슬롯 옆 연필을 눌러 이름을 직접 입력합니다. 앞뒤 공백만
털어 낸 채 적은 그대로 저장되고, 그릴 수 없는 이름이면 **이 머신에 없음** 배지가 함께 붙습니다.

### 크기와 간격

**글꼴 크기**(8~32px)와 **줄 높이**(1.0~3.0)는 본문에 적용됩니다. **본문과 연동**을 켜면 코드
크기와 줄 높이를 본문 값에서 계산하고, 끄면 아래의 코드 슬라이더 두 개를 직접 조절할 수
있습니다. 어느 쪽이든 슬라이더는 코드가 지금 실제로 그려지는 값을 계속 가리킵니다.
