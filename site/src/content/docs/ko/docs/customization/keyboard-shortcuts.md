## 보기

<!-- colwidths:182,130,153 -->

| 동작                  | macOS         | Windows / Linux |
| --------------------- | ------------- | --------------- |
| 새로고침              | `Cmd+R`       | `Ctrl+R`        |
| 소스 모드 전환        | `Cmd+/`       | `Ctrl+/`        |
| 왼쪽 사이드바 토글    | `Cmd+Shift+L` | `Ctrl+Shift+L`  |
| 확대                  | `Cmd+=`       | `Ctrl+=`        |
| 축소                  | `Cmd+-`       | `Ctrl+-`        |
| 확대·축소 초기화      | `Cmd+0`       | `Ctrl+0`        |

확대·축소는 창 전체가 아니라 에디터 내용의 배율을 바꿉니다. 트랙패드 핀치도 되고, 배율은 내장
이미지·SVG 뷰어와 PDF 리더와 공유됩니다.

새로고침은 Windows·Linux에서 OS 수준의 네이티브 단축키가 없습니다 — 그쪽에서 `Ctrl+R`은 이미
vim 모드의 실행 복귀이고, 메뉴 accelerator는 그것에 양보할 수 없습니다. 그래서 `Ctrl+R`은
조정 가능한 앱 단축키(설정 > 키 바인딩 > 보기 > 새로고침)이고 스스로 물러섭니다: vim이 그 키를
실제로 처리하고 있지 않을 때만(vim 모드가 꺼져 있거나 vim 실행 복귀 문맥 밖일 때) 새로고침하므로,
진짜 vim 실행 복귀가 가려지는 일이 없습니다. macOS에서는 `Cmd+R`이 네이티브 메뉴 accelerator이고
vim 모드는 그것을 아예 보지 못하므로(그쪽에서 `Cmd`는 vim의 실행 복귀 수식키가 아닙니다) 넘겨줄
일이 없습니다.

## 태스크

> 태스크 기능이 켜져 있어야 합니다(**설정 > 일반 > 태스크**). `Cmd+Alt+T`는 두 가지 일을 합니다. 에디터에서는 태스크 대화상자를 여는데, 커서가 있는 태스크 줄을 편집하거나 새로 만듭니다. 빠른 캡처에서는 그 대화상자를 태스크 모드로 바꿉니다.

| 동작                        | macOS         | Windows / Linux |
| --------------------------- | ------------- | --------------- |
| 태스크 입력 / 태스크 편집   | `Cmd+Alt+T`   | `Ctrl+Alt+T`    |
| 빠른 캡처                   | `Cmd+Shift+N` | `Ctrl+Shift+N`  |
| 인식된 날짜 확정            | `Tab`         | `Tab`           |

> Baram이 배경에 있어도 빠른 캡처를 태스크 모드로 여는 **전역 캡처 단축키**를 **설정 > 일반 > 태스크**에서 지정할 수 있습니다. 기본값은 없습니다 — 전역 단축키는 시스템 전체에서 가로채기 때문입니다.

### 태스크 행

**태스크 패널**과 **주간 리뷰**에서 포커스된 행에 동작합니다 — 표가 하나인 이유는, 한 곳에서 익힌 키가 다른 곳에서도 같은 뜻이기 때문입니다.

| 키                       | 동작                                |
| ------------------------ | ----------------------------------- |
| `j` / `k` (또는 `↑` / `↓`) | 행 사이 이동                       |
| `X`                      | 다음 상태로 넘기기                  |
| `T`                      | 오늘 마감                           |
| `S`                      | `#someday`로 미루기                 |
| `D`                      | 분류 메뉴 열기                      |
| `Delete` / `Backspace`   | 줄 삭제(먼저 물어봅니다)            |

> 파괴적 동작에 가까운 두 바인딩은 의도한 것입니다. 줄을 지우는 것은 `Delete`/`Backspace`뿐인데, 글자 키는 스치기가 너무 쉽기 때문입니다. 한글 자판은 물리적 키 위치로 처리하므로 IME가 켜져 있어도 `X`가 동작합니다.

## 요령

- **슬래시 명령**: 빈 줄 맨 앞에서 `/`를 입력하면 블록 삽입 메뉴가 열립니다
- **위키링크**: `[[`를 입력하면 자동완성과 함께 위키링크가 시작됩니다
- **@언급**: `@`를 입력해 페이지나 날짜를 언급합니다 — 빠른 날짜(오늘/어제/내일)나 워크스페이스의 페이지에서 고릅니다
- **각주**: `[^id]`를 입력하면 각주 참조가 들어가고, 정의는 문서 끝에 자동으로 만들어집니다
- **마크다운 단축**: 언제든 원본 마크다운 문법(예: `**bold**`, `# Heading`)을 그냥 입력해도 됩니다 — Baram이 자동으로 변환합니다
- **플로팅 툴바**: 텍스트를 선택하면 서식 항목이 있는 플로팅 툴바가 나옵니다
- **탭 전환**: `Ctrl`을 누른 채 `Tab`을 눌러 최근 쓴 탭을 훑고, `Ctrl`을 놓으면 선택됩니다
- **고스트 텍스트**: AI 자동완성이 흐린 텍스트로 나타납니다 — `Tab`으로 수락, `Cmd+Right`로 첫 단어만, `Escape`로 무시
- **찾기 및 바꾸기**: `Cmd+F`로 찾고 `Cmd+H`로 찾아 바꿉니다. `Enter`/`Shift+Enter`로 결과 사이를 오갑니다
- **접기**: 제목이나 중첩 목록 항목에 마우스를 올리면 접기 화살표가 보입니다. 클릭하거나 `Cmd+Shift+[`로 접고 펼칩니다. `Cmd+Shift+Alt+[` / `]`로 전부 접고 펼칩니다
- **날짜 언급**: `@`를 입력하고 오늘/어제/내일을 고르면 그날 저널 항목에 연결된 날짜 언급 칩이 들어갑니다
- **태그**: `#태그`를 입력합니다(볼트 전체에서 자동완성). 태그를 `Cmd/Ctrl+클릭`하면 그것을 쓰는 모든 파일을 검색합니다
- **빠른 캡처**: `Cmd+Shift+N`(또는 슬래시 명령 `/capture`)으로 무언가를 적어 둡니다. 태그가 착지 위치를 정합니다 — 노트의 제목이나 별칭과 맞는 태그가 있으면 그 노트에 덧붙습니다

## Vim 모드

**설정 > 에디터 > Vim 키 바인딩**을 켭니다(기본은 꺼짐). 스위치 하나가 **세 편집 표면**에서 vim을 켜고, 상태바가 현재 모드(`-- NORMAL --`, `-- INSERT --`, `-- VISUAL --`, 블록 편집기가 키를 잡고 있을 때 `-- INSERT (math) --`)를 보여 줍니다.

| 표면 | 가는 방법 | 쓸 수 있는 것 |
| ---- | --------- | ------------- |
| **소스 모드** | `Cmd+/` / `Ctrl+/`, 그리고 코드 파일 탭(JSON, Python 등) | 완전한 vim: 모달 편집, 이동, 오퍼레이터, 횟수, 텍스트 오브젝트(`ciw`, `di"`), `.` 반복, 검색(`/`, `n`), 마크, 매크로, 레지스터 |
| **WYSIWYG** | 보통의 리치 텍스트 에디터 | 렌더된 문서에서의 모달 편집 — 아래 명령 목록 참조 |
| **코드 블록** | WYSIWYG 문서의 코드 블록으로 들어가기(클릭 또는 이동) | 소스 모드와 같은 완전한 vim, 더하여 문서로 되돌아오는 경계 넘기 |

### WYSIWYG 명령

| 묶음 | 키 |
| ---- | -- |
| 모드 | `i` `a` `I` `A` · `o` `O` · `v`(문자 단위) `V`(줄 단위) · `Esc` |
| 이동 | `h` `j` `k` `l`과 방향키 · `0` `$` `^`(Home/End) · `w` `b` · `gg` `G`(첫 줄 / 마지막 줄 — 특정 줄은 `:N`) |
| 줄 안에서 찾기 | `f` `F` `t` `T` + 글자 하나 · `;` `,`로 반복 |
| 검색 | `/` 앞으로 · `?` 뒤로 · `n` `N` 반복 — [검색](#검색-wysiwyg) 참조 |
| 오퍼레이터 | `d` `c` `y` + 이동(`dw`, `cw`, `dj`, `d$`, `dfx`, `dgg`) · 두 번 눌러 줄 전체(`dd` `yy` `cc`) |
| 횟수 | 어떤 이동·오퍼레이터에나(`3j`, `2d3w` = 여섯 단어) |
| 편집 | `x` · `p` `P` · `u` `Ctrl+r` · `Space`로 커서 아래 태스크 항목 전환 |
| 비주얼 | `d`/`x` 삭제 · `y` 복사 · `v`/`V` 문자 단위 ↔ 줄 단위 전환 · `Esc` |
| 보기 | `zz` `z.`로 커서 줄을 화면 가운데로(비주얼 모드에서도) |
| Ex | `:w` 저장 · `:q` 탭 닫기 · `:N` / `:$` 줄로 이동 |

구조를 아는 동작: 표, 수식 블록, 이미지, 강제 개행 조각은 `j`/`k` 기준으로 각각 한 줄로 셉니다. 코드 블록은 밖에서 볼 때 한 줄입니다. 표 안에서 `h`/`l`은 셀 경계를 넘어 한 행의 모든 셀에 닿고, `j`/`k`는 열을 유지하며 아래 행으로 갑니다. 표 행에서 `dd`는 그 행을 지우고(헤더 행과 마지막으로 남은 데이터 행은 보호됩니다), 목록 안에서 `dd`는 중첩된 자식을 남깁니다. 명령 뒤에는 항상 커서가 화면 안에 유지됩니다.

WYSIWYG에 아직 없는 것 — 아래는 오늘 소스 모드와 코드 블록에서 동작합니다: 텍스트 오브젝트(`ciw`, `di"`), `.` 반복, `r`, `e`/`E`/`W`/`B`, `J`, `~`, `>>`/`<<`, `%`, `{`/`}`, `zt`/`zb`, `Ctrl+D`/`Ctrl+U`/`Ctrl+F`/`Ctrl+B` 스크롤 이동, 마크, 매크로, 이름 있는 레지스터. 비주얼 블록(`Ctrl+V`)은 리치 텍스트 표면에 넣지 않기로 한 것입니다.

### 검색 (WYSIWYG)

`/`와 `?`가 상태바에 검색줄을 엽니다. `Enter`로 이동, `Esc`로 취소, `n`/`N`으로 같은·반대 방향 반복이고, 빈 상태에서 `Enter`를 누르면 마지막 패턴을 다시 씁니다.

- 패턴은 줄 단위로 맞추는 JavaScript 정규식입니다(`^`/`$`는 줄에 걸리고 `.`은 줄을 넘지 않습니다). 대문자가 없으면 대소문자를 구분하지 않습니다(smartcase). 검색은 문서를 한 바퀴 돕니다.
- 열려 있는 문서만 검색하고, 앱의 `Cmd+F` 찾기 표시줄과는 별개입니다. 커서를 옮기며, 결과를 강조하지는 않습니다.
- 코드 블록 안에 걸리면 커서가 그 블록으로 들어갑니다. 검색줄에는 IME로 한글을 입력할 수 있습니다.

### 코드 블록 경계

| 키 | 동작 |
| -- | ---- |
| 블록으로 들어가는 `j` / `k`(또는 방향키) | 열을 유지한 채 블록의 첫 줄 / 마지막 줄로 들어갑니다 |
| 인서트 모드에서 방향키 | 블록으로 들어가 계속 입력합니다 — 인서트 모드가 이어집니다 |
| `Esc`(노멀 모드에서) | 블록을 나와 문서 수준 vim으로 돌아갑니다 |
| 마지막 / 첫 줄에서 `j` / `k`(또는 방향키) | 블록을 아래로 / 위로 나갑니다 |
| `u` / `Ctrl+r` | **문서** 기록을 실행 취소·복귀합니다 — 블록 안과 밖의 편집이 한 스택을 공유합니다 |

키보드로 움직이든 마우스로 클릭하든, 모드가 양방향으로 커서를 따라 경계를 넘습니다. 인서트 상태로 블록을 나오면 문서도 인서트이고, 블록 안에서 `Esc`를 누르면 나올 때 문서도 노멀입니다. 블록 사이나 문서로 되돌아가는 클릭은 어떤 모드에서도 동작합니다. 블록 안에서 `:`과 `/`는 vim 자신의 프롬프트를 열고, 거기 입력한 키는 프롬프트에 머무릅니다. 알려진 한계: 코드 블록 안에서 `zz`/`z.`는 아무 일도 하지 않습니다(블록이 스스로 스크롤하지 않고 문서와 함께 스크롤합니다).

### 블록 편집기 (수식, Mermaid, SVG, HTML, 쿼리)

이 블록들은 문서에서 원자입니다. `j`/`k`는 각각을 한 줄로 다루고 `dd`는 블록 전체를 지웁니다. 블록을 선택한 상태에서 `i`를 누르면 그 편집기가 열리고(상태바에 `-- INSERT (math) --` 등이 표시됩니다), `Esc`를 누르면 블록이 여전히 선택된 채 노멀 모드로 돌아옵니다. 노멀 모드에서의 클릭은 블록을 열지 않고 선택만 합니다.

### Ex 명령

세 표면 모두에서 쓸 수 있습니다. 입력하는 동안 상태바에 명령줄이 나타나고, `Enter`로 실행, `Esc`로 포기하며, 빈 줄에서 `Backspace`를 누르면 닫힙니다.

| 명령 | 동작 |
| ---- | ---- |
| `:w` / `:write` | 현재 파일 저장 |
| `:q` / `:quit`  | 현재 탭 닫기(저장하지 않은 변경 확인이 적용됩니다) |
| `:N`(예: `:42`) | N번째 줄로 — 줄은 `j`/`k`가 세는 방식으로 셉니다. 강제 개행 조각이나 표 행은 한 줄이고 코드 블록도 한 줄입니다. 범위를 넘는 숫자는 마지막 줄로 갑니다 |
| `:$`            | 마지막 줄로 |

소스 모드와 코드 블록은 CodeMirror 어댑터 자신의 ex 명령과 `/` 검색도 받습니다. WYSIWYG은 위 네 개만 인식합니다.

**한글 IME**: 세 표면 모두에서 한글 입력 소스가 켜져 있어도 vim 명령이 동작합니다 — 노멀·비주얼 모드에서 키는 물리적 위치로 해석되고(`j` 키를 누르면 `ㅓ`가 입력될 자리에서도 아래로 움직입니다), 낱자가 끼어드는 것도 막습니다. 인서트 모드에서는 한글이 정상적으로 입력됩니다. WYSIWYG에서 `f` 뒤에 자음 낱자를 누르면 초성으로 이동합니다(`f` `ㄱ`이 강, 김, 그를 찾습니다). 이 동작은 macOS에서 확인했고 Windows·Linux는 아직 검증하지 않았습니다.

vim 레지스터는 앱 전체에서 공유되고(클립보드처럼) 디스크에 쓰이지 않습니다. 코드 블록 안에서 복사한 것을 아직 밖에 붙일 수는 없고, 그 반대도 마찬가지입니다. Vim 키 시퀀스는 설정 > 키 바인딩에서 재지정할 수 없습니다.

## 사용자 지정

모든 키보드 단축키는 **설정 > 키 바인딩**에서 다시 지정할 수 있습니다. 이름이나 키로 단축키를 검색하고 **편집**을 클릭한 뒤 새 키 조합을 누릅니다. 충돌은 자동으로 감지됩니다. ↺ 버튼으로 단축키를 하나씩 초기화하거나, **모든 단축키 초기화**로 기본값으로 되돌립니다. Vim 키 시퀀스(위 참조)는 별개 계층이고 여기서 재지정할 수 없습니다.
