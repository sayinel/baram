## 삭제와 복원

하이라이트 삭제는 **소프트 삭제**입니다. 항목은 삭제 시각과 함께 제자리에 남고, 겹쳐 그리기가
멈추며, 하이라이트 패널의 **삭제됨** 하위 탭으로 옮겨집니다.

의도한 것입니다. 인용문은 짝 노트에 살고 도형 정보는 사이드카에 삽니다. 항목을 곧바로 버리면 그것을
가리키던 모든 참조가 80자짜리 맨 라벨로 주저앉고, 영역 참조는 잘라 낸 사각형을 잃어 **되살릴 수
없게** 됩니다. 소프트 삭제는 두 종류의 참조를 온전히 지킵니다.

삭제됨 탭에서 할 수 있는 일:

- **복원** — 하이라이트가 참조까지 그대로 되돌아옵니다
- **완전 삭제** — 항목이 영구히 사라집니다. Baram이 먼저 그것을 가리키는 참조가 몇 개인지 세어
  확인 창에서 알려 줍니다. 그 참조들이 미리보기를 잃기 때문입니다. 인용문은 어느 쪽이든 짝 노트에
  남습니다.

## 하이라이트가 저장되는 곳

데이터베이스에 숨는 것은 없고, PDF에 쓰는 것도 없습니다.

| 파일 | 내용 |
| ---- | ---- |
| `highlights/<PDF-경로>.md` | 하이라이트마다 인용문을 담은 짝 마크다운 노트. 하이라이트 하나당 블록 ID가 붙은 문단 하나 |
| `.baram/pdf-highlights/<PDF-경로>.json` | 도형 정보 — 페이지 번호, 사각형, 색, 종류, 삭제 상태 |

둘 다 볼트 안의 평범한 텍스트라서 다른 모든 것처럼 diff·머지·동기화됩니다. 짝 노트는 보통 마크다운
파일입니다 — 열어서 하이라이트를 독서 목록처럼 읽고, 그 주위에 글을 쓸 수 있습니다.

사이드카의 항목 하나가 잘못돼 있으면 파일 전체를 끌고 가지 않고 그 항목만 버립니다. 그래서 나쁜
레코드 하나가 그 문서의 하이라이트 전부를 잃게 만들 수 없습니다.

## PDF로 링크하기

PDF는 평범한 링크 대상입니다. `[[paper.pdf]]`가 해석되어 리더에서 열리고, 위키링크 자동완성이 볼 수
있는 파일을 제시하며 종류를 표시하고, 평범한 마크다운 링크 —
`[그 논문을 보라](papers/attention.pdf)` — 도 OS에 넘기지 않고 앱에서 엽니다.
이것들이 실제 간선으로 색인되므로 PDF가 백링크와 그래프에도 나타납니다.
