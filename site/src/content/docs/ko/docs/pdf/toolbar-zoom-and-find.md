Baram은 `.pdf` 파일을 내장 리더로 엽니다. PDF를 편집할 수는 없지만, 읽고 검색하고 하이라이트할
수 있으며, 모든 하이라이트가 마크다운 노트 안의 참조가 될 수 있습니다. **PDF 파일 자체에는 절대
쓰지 않습니다.** 하이라이트는 그 옆에 평범한 파일로 볼트에 저장됩니다([하이라이트가 저장되는 곳](/baram/ko/docs/pdf/managing-highlights/#하이라이트가-저장되는-곳) 참조).

> 하이라이트에는 볼트가 필요합니다. 하이라이트를 어딘가에 저장해야 하기 때문입니다. 볼트 밖의
> PDF를 **파일 > 파일 열기**로 열어도 리더·찾기·확대·페이지 목록은 그대로 쓸 수 있고,
> 하이라이트 컨트롤만 나오지 않습니다.

## PDF 툴바

| 컨트롤 | 하는 일 |
| ------ | ------- |
| **페이지·하이라이트 목록** | 사이드 패널을 열고 닫습니다(아래 참조) |
| **‹ / ›** 와 `3 / 40` | 이전·다음 페이지, 그리고 현재 페이지 표시 |
| **찾기** | 찾기 표시줄을 엽니다(`Cmd+F`도 같습니다) |
| **텍스트 하이라이트 모드** | 텍스트를 선택하면 단순 선택이 아니라 하이라이트가 만들어집니다 |
| **영역 하이라이트 모드** | 그림·표·수식 위로 끌어 사각형을 그립니다 |

두 하이라이트 모드는 서로 배타적입니다 — 하나를 켜면 다른 하나가 꺼집니다. 둘 다 기본은 꺼짐이라,
평범한 드래그 선택과 `Cmd+C`는 다른 PDF 리더와 똑같이 동작합니다.

## 확대·축소

PDF는 캔버스에 렌더되므로 에디터와 같은 컨트롤로 배율이 바뀝니다 — `Cmd+=` / `Cmd+-`로 단계적으로,
트랙패드에서는 두 손가락 핀치로. 배율이 정해지면 페이지가 그 배율에 맞게 다시 선명하게 렌더되고,
흐릿한 비트맵으로 늘어나지 않습니다.

## PDF에서 찾기 (`Cmd+F`)

PDF 안에서 `Cmd+F`는 에디터의 찾기 표시줄이 아니라 **PDF에서 찾기**를 엽니다.

- 입력하면 문서 전체의 결과가 강조됩니다
- **↑ / ↓** 또는 `Enter` / `Shift+Enter`로 결과를 오가고, 표시기가 `3 / 17`을 보여 줍니다
- **대소문자 구분**으로 검색을 좁힙니다
- `Escape`로 표시줄을 닫습니다

결과는 PDF의 텍스트 레이어 위에 그려지므로, PDF 내부 텍스트가 줄에 걸쳐 끊겨 있어도 페이지의 단어와
정확히 겹칩니다.

## 사이드 패널

패널 버튼을 누르면 PDF 왼쪽에 레일이 열리고 탭이 둘 있습니다.

- **페이지** — 모든 페이지의 축소판. 스크롤하면서 필요할 때 렌더됩니다. 클릭하면 그 페이지로 이동합니다.
- **하이라이트** — 이 PDF의 모든 하이라이트를 페이지 순서로. 클릭하면 그리로 이동해 잠깐 반짝입니다.
  이 탭에는 **활성**과 **삭제됨** 하위 탭이 있습니다([삭제와 복원](/baram/ko/docs/pdf/managing-highlights/#삭제와-복원) 참조).

패널 안쪽 경계를 끌어 폭을 조정합니다. 폭은 설치 단위로 기억됩니다.
